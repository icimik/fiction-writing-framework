# 质量检查清单

## A. 设定一致性

- [ ] 名称规范统一（机构/地名/平台/势力）
- [ ] 能力体系有代价与边界
- [ ] 时间线无矛盾
- [ ] 设定术语前后一致

## B. 角色与叙事

- [ ] 关键行为符合角色动机
- [ ] 无明显 OOC
- [ ] 视角切换清晰且可追踪
- [ ] 信息释放不倾倒

## C. 情节节奏

- [ ] 本章有明确推进目标
- [ ] 至少一个有效冲突
- [ ] 章末有钩子
- [ ] 伏笔新增和回收有记录

## D. 生产与运营

- [ ] 本章完成后更新工作日志
- [ ] 重要变更已登记到变更记录
- [ ] 反馈已归档并形成调整结论
- [ ] 周期复盘按计划执行

## E. 变更纪律与交付规范

- [ ] 单次仅变更一个对象（章节/大纲/设定）
- [ ] 章节改写为整章重写，非局部替换或简单追加
- [ ] 未创建 `.bak` / `_old` 等正文副本
- [ ] 字数符合要求，格式符合章名与分节规范
- [ ] 风格、视角、节奏保持一致
- [ ] 生成后编码检查通过（无乱码/异常字符）

## F. 多Agent协作验收

- [ ] 当前对象已完成 Reviewer + Reader + Editor 三方审阅，未越级切换对象
- [ ] Reader 反馈基于至少 3 个角色卡生成，并已在汇总中标注
- [ ] Editor 已输出三段式结果（汇总反馈 -> 改稿指令 -> 验收结论）
- [ ] 若触发联动更新，Editor 已按 `模板_联动更新清单` 完成勾检
- [ ] 未通过项已回退到改稿环节，未进入下一章节/下一对象

## G. 证据与追溯

- [ ] Reviewer 问题项均可定位（位置、违反规则、修复建议、证据来源齐全）
- [ ] Editor 每条关键结论均附信息来源引用（路径 + 条目/段落）
- [ ] Editor 的 P0 项至少具备 2 个来源（Reviewer + Reader 各至少 1 条）
- [ ] 本轮结论与改动已同步记录到变更记录与工作日志，能追溯到章节/设定项

## H. 短篇小说集横向检查

- [ ] 单篇审阅之外，已完成整组篇章横向比对
- [ ] 开篇方式不存在明显模板化重复
- [ ] 章节结构不存在成组镜像（如相同第二章功能位、相同中段揭示位）
- [ ] 同地区篇章保持统一制度语义，但阅读入口与冲突承载方式有差异
- [ ] 已明确哪些篇目为正式章节、哪些仍为样稿或归档稿

## I. 同世界观导入融合检查

- [ ] 导入资产已归档到 `99-archive/import-YYYYMMDD/`
- [ ] 已完成导入资产清单与融合评估
- [ ] 每项导入资产均有处理结论（保留 / 改写并并入 / 拆分吸收 / 仅归档）
- [ ] 导入后已复核核心设定、命名规则、时间线、阵营职能一致性
- [ ] 导入影响已同步更新到 foundation / outline / rules / logs / change-log
