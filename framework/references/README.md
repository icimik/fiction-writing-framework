这些文档是参考层，不直接替代框架主文档，也不作为执行模板入口。

若需要执行层直接引用的现行硬规格，请改查 `framework/07-specifications/`。

## 使用规则

1. 主文档负责“必须执行的最小规范”。
2. 参考文档负责“方法深度、案例和历史镜像”，不直接承担执行规范职能。
3. 参考内容落地时，必须先转写到流程文档、模板、检查清单或项目资产中，再执行。
