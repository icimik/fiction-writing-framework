# 中文语言原始参考

本目录存放中文语言材料的原始提取稿或整理底稿。

这些文档保留较多教材层级、案例密度和提取痕迹，主要用途是：

1. 追溯 `framework/07-specifications/language/` 的上游来源。
2. 在项目短参考不足以裁决时，回看更完整的定义、分类、例项和讲义结构。
3. 保留原始整理链，避免框架现行规格与源材料混写。

## 使用规则

1. 本目录属于 `references/`，只负责追溯与扩展阅读。
2. 高频执行入口仍应优先使用 `framework/07-specifications/language/`。
3. 若项目需要项目级语言摘要，应从 `07-specifications/` 与本目录中筛选，不得直接把整份提取稿塞进 `STYLEGUIDE.md`。
