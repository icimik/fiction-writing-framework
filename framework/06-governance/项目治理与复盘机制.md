# 项目治理与复盘机制

## 治理目标

- 保证创作资产结构统一。
- 保证规则执行可检查、可追踪。
- 保证反馈驱动的持续迭代。

## 统一项目目录规范

每个项目必须包含以下一级目录：

- `00-intake/`
- `01-brief/`
- `02-research/`
- `03-foundation/`
- `04-outline/`
- `05-rules/`
- `06-analysis-research/`
- `07-writing/`
- `08-operations/`
- `09-assets/`
- `99-archive/`

## 复盘频率

- 每周：产出、问题、下周动作。
- 每月：趋势、策略、方向调整。
- 每 N 章：节奏与读者反馈校正。
- 每卷：结构完整性和商业性评估。

## 变更治理

所有重大变更必须同步：

1. 变更记录
2. 受影响文件清单
3. 规则更新
4. 后续风险与回滚说明

## 版本管理建议

- 规则文档采用 `vX.Y` 标注。
- 关键里程碑节点留快照。
- 复盘报告统一命名并按时间排序。
