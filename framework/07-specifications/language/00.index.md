# 中文语言规格索引

本索引收纳 `fiction-writing-framework` 当前使用的中文语言核心规格。

这些文档不是简单教材摘抄，也不是只剩结论的压缩摘要，而是在保留正式定义、核心分类、关键概念和主要用法指南的前提下，重组为框架可执行规格。

## 文档定位

- 目标：为虚构文学创作提供可直接调用的中文语言基线。
- 适用：长篇、连载、短篇集、多 POV、推理、现实向、强风格约束项目。
- 不替代：
  - 项目级 `STYLEGUIDE.md`
  - 项目级“写作语言参考”
  - 题材专属术语手册

## 使用顺序

1. **先读 `中文生成约束.md`**——这是生成正文时的操作手册，优先级最高。
2. 再读项目级 `STYLEGUIDE.md`。
3. 再读项目级"写作语言参考"。
4. 若需要追溯中文语言硬标准，再读下方分册。
5. 若分册仍不足以裁决，再回项目自带教材、讲义或术语材料。

## 文档层级

### 生成约束（生成时必读）

#### `中文生成约束.md`

面向 LLM 的生成时操作手册。不是语言学参考，不是教材整理。

处理重点：

- LLM 翻译腔的成因与机制
- 12 种高频翻译腔模式的识别特征、反面示例与正面替换
- 生成时三阶段检查（生成前、生成中、生成后）
- "看似高级实则翻译腔"的句式黑名单
- 中文叙事正面特征锚定

适合解决：

- "每句话都说得通，但读起来不像中文"
- "STYLEGUIDE 写了不要翻译腔，但依然在翻译"
- "精修一直在改表面，根源改不掉"

### 1. `现代汉语_词汇规范.md`

处理重点：

- 词义准确性
- 近义词取舍
- 语体与身份匹配
- 叙述词与对白词的分工
- 抽象词、方便词、评判词的收束边界
- 典型正例与误例对照

适合解决：

- “意思差不多，但不像这个人会说的话”
- “信息对了，但口气漂了”
- “句子看着顺，落点却虚”

### 2. `现代汉语_语法规范.md`

处理重点：

- 句子是否成立
- 主干是否可复原
- 主谓、动宾、偏正、补语等搭配关系
- 合法省略与坏省略
- 多 POV 叙事中的代词、指代链和误认写法
- 典型正例与误例对照

适合解决：

- “逻辑没错，但这不是中文句子”
- “场面想写轻，结果把主干写没了”
- “多人同场时代词乱飞”

### 3. `现代汉语_修辞规范.md`

处理重点：

- 修辞目标与语境边界
- 词语锤炼和句式选择
- 长短句、整散句、主动被动、肯定否定的功能区分
- 推理小说中的修辞限位
- 反 AI 腔、反口号腔、反命题先行
- 典型正例与误例对照

适合解决：

- “句子有劲，但把证据盖住了”
- “段落漂亮，却没有叙事任务”
- “越想写文学性，越像作者在表演”

## 调用规则

1. 不把分册逐段塞进项目 `STYLEGUIDE.md`；项目文档只保留必要摘录和裁决。
2. 复核正文时，优先把问题归类到“词汇 / 语法 / 修辞”，再决定是否重写。
3. 若某条项目规则长期高频复用，应先回写到本规格层，再同步到模板或清单。
