# 规格文档层

本目录用于存放框架内部的现行规格文档。

它和其他层级的职责区别如下：

- `framework/01-methods/`：方法原则与工具，回答“怎么做”。
- `framework/02-process/`：执行流程，回答“先做什么、后做什么”。
- `framework/03-templates/`：落地模板，回答“具体怎么写文档”。
- `framework/references/`：历史追溯与扩展阅读，回答“原文依据和镜像在哪里”。
- `framework/07-specifications/`：框架认可的现行规格，回答“哪些硬标准应直接引用”。

## 使用规则

1. 当项目存在明确的中文表达要求、去翻译腔要求、句法成立要求或长期连载风格稳定要求时，优先查本目录。
2. 本目录是执行层可直接引用的规格层，不属于历史镜像。
3. 项目级 `STYLEGUIDE.md` 与“项目写作语言参考”应优先引用本目录，再按题材和项目实际做二次压缩。
4. 若项目还有专门教材、讲义、术语手册，可作为补充来源，但不得绕开本目录直接把厚材料变成高频入口。
5. 本目录若引用原始教材提取稿，应将上游底稿放入 `framework/references/`，而不是混放在规格层。
