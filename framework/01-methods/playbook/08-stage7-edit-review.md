# 阶段7：整书审读、中文表达精修与中文重塑（方法分册）

> 本分册对应标准流程阶段 7（整书审读与中文表达精修）和阶段 7b（中文重塑）。
> 执行入口与硬规则以 `framework/02-process/标准创作流程.md` 阶段 7 / 7b 为准，本文只提供方法论支撑。

## 本阶段核心创作原则

- **只改表达，不改结构**：正文的因果链、信息释放顺序、章尾钩子、人物弧线不在本阶段改动。
- **重述优先于修改**：默认从叙事任务出发重新写，而不是在原文上改。
- **分层优先于通改**：每次只处理一种问题（对白 / 段首段尾 / 删减），不一次通改全部。
- **删比改有效**：删不会引入新的翻译腔，改会。

## 理论基础

### LLM 翻译腔的成因

LLM 用英语语料训练，即使输出中文也倾向于：
- 使用压缩名词做主语（"这份报告的调查结果"）
- 使用使役动词（"使他感到""让她意识到"）
- 过度使用连接词堆叠因果逻辑（"然而……因此……与此同时"）
- 概念先行再展开（"作为一名护士，她……"）
- 用情绪标签替代展示（"他感到一阵深深的无力"）

这些模式在精修时不会自动消失——用同一个 LLM 精修它自己生成的翻译腔，往往只是把"翻译腔 A"改成"翻译腔 B"。

### 锡定效应（Anchoring）

LLM 在给定原文时，会被原文句法骨架锡定，只能做表面词汇替换。"修改这段话"这个指令本身就暗含了"保留原文结构"的假设——而原文结构正是翻译腔的来源。

**判断标准**：一段文本经过一轮"给 LLM 原文让它改"后朗读仍不自然，必须立即切换到重述法。

## 四种核心方法

### 方法 1：重述法（阶段 7 默认方法）

不给 LLM 原文，只给叙事任务，让它重新写。

操作：
1. 用一两句话提取当前段落的叙事任务：谁在哪里做什么，发生了什么，结果是什么。
2. 用具体事件描述，不用抽象概括。
   - 正确："他在药房柜台前站了五分钟，最后把止痛药放回去。"
   - 错误："展现贫困对日常生活的影响。"
3. 让 LLM 从叙事任务出发写这一段，不提供原文。
4. 写完后核对：新段落是否保留了原段的信息点（人名、时间、物件、因果关系）。

### 方法 2：锚文本法（语感校准辅助）

给 LLM 一段达标的中文小说段落作为语感样本。

操作：
1. 从项目 `09-assets/项目写作语言参考_*.md` 中抽取 100-200 字的锚文本。
2. 放在 prompt 开头，说"按这个语感重写下面的段落"。
3. 200 字的锚文本比 2000 行规则文档更能校准语感。

### 方法 3：分层法（高风险章节专用）

不一次精修全部，分三轮各管一种问题：

1. **对白轮**：只改对白，按角色身份和当下状态重写，不碰叙述。
2. **段首段尾轮**：只改段首和段尾——翻译腔最密集的位置。
3. **删减轮**：只删，不改写——删冗余连接词、情绪标签、总结句。

### 方法 4：删减法（可叠加到任何方法之后）

只做减法：
1. 删所有可删连接词（"然而""因此""与此同时"），看句意是否成立。
2. 删所有"使得""导致""意味着""让他感到"，强制补具体动作。
3. 删段尾总结句。

## 阶段 7 与阶段 7b 的区别

| 维度 | 阶段 7：整书精修 | 阶段 7b：中文重塑 |
|------|----------------|-----------------|
| 输入 | 原文 | 叙事任务清单（原文仅用于提取） |
| 操作 | 重述法 + 分层法 + 删减法 | 从叙事任务重建 + 对白轮 + 删减轮 |
| 默认方法 | 重述法 | 逐章重建 |
| 触发条件 | 全书结构稳定，表达层需校正 | 阶段 7 完成后 >30% 章节仍有翻译腔 |
| 禁令 | 禁止在原文上反复重试 | 禁止参考原文句式 |

## 操作禁令

- 禁止"给 LLM 原文让它改"超过一轮。
- 禁止"通读全章逐句润色"。
- 禁止在精修中引入原文没有的信息、情绪标签或因果解释。
- 禁止对重建稿（7b）参考原文的句式和句法结构。

## 审阅自检

- □ 逻辑与结构未被误改
- □ 默认使用重述法，非逐句润色
- □ 高风险章节已分层处理
- □ 删减轮已执行
- □ 无翻译腔高频反模式残留（压缩名词主语、使役动词、概念先行、情绪标签）
- □ 整书回读后前后气质一致
