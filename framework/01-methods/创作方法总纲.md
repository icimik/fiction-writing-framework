# 创作方法总纲

## 方法定位

本总纲用于统一“理论-技法-实战”的创作方法，适用于网文、轻小说、虚构文学长中短篇。

说明：本文件属于框架主文档（执行规范）。细化原则与工具已内化为 `framework/01-methods/rulebook/` 分册，不再仅作为外部提醒。

## 核心原则

1. 先定边界，再写内容。
2. 先保完成，再求完美。
3. 先做验证，再做放量。
4. 规则一致性优先于局部炫技。

## 理论锚点（方法总览）

1. 前提法则：用一句可证伪的命题统一作品内核。
2. 情绪净化：情节服务于读者情绪积压与释放。
3. 复调冲突：正反双方都具备自洽价值观。
4. 次级信仰：世界规则必须长期稳定可验证。
5. 能力代价：能力越强，限制与代价越明确。
6. 陌生化表达：文风不套话，细节可感知。
7. 晶体叙事：主线是晶核，支线必须回扣主线。

## 方法主链

1. 前提法则：一句话定义作品内核冲突。
2. 受众匹配：锁定核心读者而非泛读者。
3. 设定闭环：世界规则、能力代价、社会结构互相约束。
4. 角色驱动：行为由动机、创伤、欲望推动。
5. 节奏控制：单章钩子、单元小高潮、卷级大高潮。
6. 伏笔回收：埋设必须有计划回收。
7. 迭代修订：按反馈调整，不破坏核心主线。

## 八阶段执行映射

1. 启动准备：定品类、篇幅、核心卖点、前提句。
2. 选题定位：做赛道匹配与差异化设计。
3. 世界搭建：规则、代价、势力、社会结构闭环。
4. 角色塑造：创伤-谎言-弧光与关系网络联动。
5. 情节规划：卷章结构、爽点节奏、伏笔台账。
6. 叙事打磨：视角稳定、信息释放、语言可读。
7. 初稿生产：固定流水线与断章钩子机制。
8. 审阅与续航：三轮改稿+周期运营复盘。

## 文学性创作分项（01-method 扩展）

1. 文学性不是慢节奏，而是“情节有效 + 意义密度高”。
2. 角色不是观点容器，而是价值冲突中的行动者。
3. 主题不靠口号表达，靠可追溯的行为后果表达。
4. 修辞不为华丽服务，优先为叙事清晰与情绪强度服务。
5. 反套路的核心不是反常识，而是高可信的意外。

## 使用建议

1. 日常执行优先遵循本总纲与流程主文档。
2. 日常执行直接使用 `framework/01-methods/rulebook/` 分册，不跳过。
3. 当需要追溯原文或比对版本时，再进入 `framework/references/`。
3. 任何参考内容落地到项目前，都需转化为项目规则或操作清单。

## 交付要求

- 所有项目都需提供：前提句、受众描述、主冲突、分卷结构。
- 所有章节都需提供：推进目标、核心冲突、章末钩子。
- 所有改动都需提供：变更原因与影响说明。

补充：长篇连载项目还需提供读者画像、反馈处理记录、周/月/N章/分卷复盘。
