# 参考文本使用规范（Rulebook）

## 可执行条款

1. 参考文本仅用于拆解结构与技法，不得直接拼接改写。
2. 拆解至少覆盖：结构、节奏、角色、信息释放四维。
3. 每次引用参考文本必须生成“借鉴点-改造点”对照表。
4. 成果必须转化为本项目原创表达，不得保留可识别复刻段落。
5. 参考文本使用记录必须归档。

## 产出要求

- `参考文本拆解表.md`
- `借鉴-改造对照表.md`
- `风险说明.md`

## 检查项

- [ ] 引用目的明确（学结构/学节奏/学叙事）。
- [ ] 有明确原创改造策略。
- [ ] 无高相似段落。
- [ ] 拆解结论可转化为执行动作。
- [ ] 使用记录可追溯。

## 失败判定

- 直接套用参考文本表达。
- 只有“喜欢/不喜欢”主观结论，无结构分析。
- 参考使用后未产出可执行改进项。
