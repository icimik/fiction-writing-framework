# 叙事规范（Rulebook）

## 可执行条款

1. 每章固定主视角；视角切换必须有明确边界。
2. 叙事距离需标注策略（近/中/远），并保持一致性。
3. 信息释放遵循“必要即给”，不得超前剧透核心谜底。
4. 时间结构必须显式管理（线性/插叙/并行），避免时间混乱。
5. 叙述声音需稳定：语气、词汇层级、叙述立场不频繁跳变。

## 产出要求

- `视角信息表.md`
- `叙事距离标注.md`
- `时间结构表.md`

## 检查项

- [ ] 读者能明确当前视角主体。
- [ ] 关键信息没有越权泄露。
- [ ] 时间线可追踪，无前后矛盾。
- [ ] 叙述声音统一且可识别。
- [ ] 信息密度与节奏匹配（不过载/不过空）。

## 失败判定

- 视角乱跳导致理解中断。
- 时间线错位影响因果关系。
- 叙述口吻断裂破坏沉浸感。
