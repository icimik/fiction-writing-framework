# 修辞与文风规范（Rulebook）

## 可执行条款

1. 文风先定后写：章节内风格不漂移。
2. 展示优先于讲述：关键情绪用动作/场景承载。
3. 场景与概述比例需控制，避免全概述或全描写。
4. 对话需有功能：推进情节/揭示人物/制造张力。
5. 套语与空词需清理，保留有效意象。

## 产出要求

- `风格指南.md`
- `意象与禁用套语表.md`
- `场景/概述比例记录.md`

## 检查项

- [ ] 关键段落有可视化细节。
- [ ] 对话可区分人物，不同角色口吻不同。
- [ ] 冗词、赘述、空泛句已删减。
- [ ] 文风与题材匹配。
- [ ] 没有破坏节奏的无效描写。

## 失败判定

- 文风混杂且无统一基调。
- 大段解释性文字替代叙事。
- 对话只传信息不塑造冲突。
