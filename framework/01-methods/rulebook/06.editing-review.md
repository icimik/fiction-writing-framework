# 审阅与改稿规范（Rulebook）

## 可执行条款

1. 改稿顺序固定：结构层 -> 角色层 -> 语言层。
2. 每轮改稿必须形成问题清单与处理结论。
3. 改稿项需标注优先级（必须/建议/观察）。
4. 每次提交前必须完成格式与发布检查。
5. 同类问题连续出现 3 次必须升级为规则条款。
6. 语言层精修默认使用重述法（从叙事任务重写），禁止在原文上反复重试超过一轮。若整书精修后仍有系统性翻译腔，按阶段 7b 中文重塑流程处理。详见 `framework/02-process/标准创作流程.md` 阶段 7 / 7b。

## 产出要求

- `三层修订清单.md`
- `问题日志.md`
- `审阅结论.md`
- `投稿与格式检查表.md`

## 检查项

- [ ] 结构问题先于文句润色解决。
- [ ] 角色逻辑与剧情逻辑一致。
- [ ] 改稿后可读性实质提升。
- [ ] 所有“必须修改项”已闭环。
- [ ] 版本差异有记录。

## 失败判定

- 只做语言润色，不修结构根因。
- 问题重复出现且无机制修复。
- 缺少可追溯的改稿记录。
