# 共享评审模板规范（Rulebook）

## 可执行条款

1. 所有项目统一使用共享评审模板字段，不得私自删核心项。
2. 评审至少覆盖：规则一致性、角色驱动性、情节因果性、叙事有效性、语言可读性；网文连载额外记录章节钩子强度。
3. 每条问题必须包含：位置、影响、建议、优先级。
4. 评审结论必须包含“是否可发布”判断。
5. 评审后必须产出修复记录与复验结果。

## 标准评审结构

- 作者建议
- 编辑建议
- 执行标准
- 实施记录
- 失败样例
- 量化阈值

## 检查项

- [ ] 评审条目完整。
- [ ] 问题描述可定位。
- [ ] 建议可执行而非泛泛而谈。
- [ ] 修复闭环有证据。
- [ ] 量化阈值有更新依据。
- [ ] 若为网文连载，已记录章节钩子强度并据此判断是否过线。

## 失败判定

- 评审只给评分不提问题。
- 建议不可落地。
- 修复后未复验即通过。
