# 类型适配规范（Rulebook）

## 可执行条款

1. 立项时必须指定主类型与辅类型，不得模糊混写。
2. 类型目标、风险与读者期待必须显式写出。
3. 每种类型必须匹配对应工具链与产出模板。
4. 类型反模式必须预先规避并写入检查表。
5. 类型切换或融合时，需记录策略与边界。

## 产出要求

- `类型策划卡.md`
- `类型风险清单.md`
- `类型工具链选择记录.md`

## 检查项

- [ ] 主辅类型边界清晰。
- [ ] 关键爽点/共情点符合类型预期。
- [ ] 反模式监控已执行。
- [ ] 类型标签与实际内容一致。
- [ ] 平台与类型适配合理。

## 失败判定

- 类型目标与写作内容错位。
- 融合类型导致叙事失焦。
- 反模式长期未处理。
