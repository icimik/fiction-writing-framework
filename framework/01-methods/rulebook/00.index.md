# Guide 规范版索引

本目录是 `guide` 的框架规范版（rulebook），仅保留可执行条款与检查项。

## 执行顺序

1. `01.worldbuilding.md`
2. `02.character.md`
3. `03.plot.md`
4. `04.narrative.md`
5. `05.rhetoric.md`

## 执行约束

- 每阶段必须产出“文档+检查记录”。
- 任何跳步必须在工作日志记录原因与风险。
- 规范版优先于原文版；原文版仅用于细节追溯。
