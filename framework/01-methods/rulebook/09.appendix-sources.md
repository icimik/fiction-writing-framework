# 资料与来源规范（Rulebook）

## 可执行条款

1. 关键结论必须标注来源类型（数据/经验/推断）。
2. 涉及市场判断时必须区分“已验证数据”与“推断”。
3. 来源记录需可追溯到文件或链接。
4. 低可信来源不得作为唯一依据。
5. 复盘报告中必须注明结论证据链。

## 产出要求

- `来源索引.md`
- `证据链说明.md`
- `结论可信度标注.md`

## 检查项

- [ ] 关键判断均有来源。
- [ ] 推断性结论已明确标注。
- [ ] 来源口径冲突已说明。
- [ ] 过期来源已更新或降权。
- [ ] 证据链与行动建议一致。

## 失败判定

- 重要结论无来源支撑。
- 推断被当作确定事实。
- 证据链断裂导致错误决策。
