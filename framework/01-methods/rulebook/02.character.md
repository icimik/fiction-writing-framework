# 角色规范（Rulebook）

## 可执行条款

1. 核心角色必须包含：身份、目标、动机、缺陷、创伤、弧光。
2. 主角必须区分“想要”与“需要”，并在剧情中产生张力。
3. 反派必须具备自洽立场，不得仅以“邪恶”驱动。
4. 关系网络必须可视化：盟友、对手、利益冲突、依赖关系。
5. 每个关键角色必须有至少 1 个高光行为节点。

## 产出要求

- `角色卡.md`
- `关系矩阵.md`
- `角色弧线表.md`

## 检查项

- [ ] 关键行为能追溯到角色动机。
- [ ] 不存在明显 OOC 行为。
- [ ] 配角不是工具人（有独立目标）。
- [ ] 关系变化有触发事件支持。
- [ ] 角色成长不是口头宣告而是行为变化。

## 失败判定

- 角色行为服务作者意图而非人设逻辑。
- 角色关系只靠设定说明，无剧情体现。
- 反派动机空洞导致冲突失真。
