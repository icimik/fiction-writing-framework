# 情节规范（Rulebook）

## 可执行条款

1. 主线目标必须在开篇明确，且每 3-5 章可观察推进一次。
2. 每章必须有：核心冲突、推进目标、章末钩子。
3. 结构必须选型并固定（如三幕式/分卷式），禁止中途无理由切换。
4. 伏笔必须登记：埋设位置、回收节点、回收状态。
5. 大纲变更必须走联动更新：人设、设定、伏笔同步校正。

## 产出要求

- `分卷大纲.md`
- `单章节拍表.md`
- `伏笔-回收表.md`
- `冲突矩阵.md`

## 检查项

- [ ] 主线与支线关系清晰，支线能反哺主线。
- [ ] 冲突升级存在梯度，不平推。
- [ ] 高潮前存在“发现/突转”机制。
- [ ] 章末钩子不重复同质。
- [ ] 伏笔回收率达到计划值。

## 失败判定

- 大量水情节不推动主线。
- 反转无铺垫、仅为反转。
- 大纲更新后未同步关联文档。
