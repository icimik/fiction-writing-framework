# 模板_编辑修订与投稿检查

## 三层修订清单

```markdown
# 三层修订清单
## 结构层
- 是否存在明确诱发事件？示例：第1章末出现通行证异常
- 中段是否失速？示例：第6章增加“盟友失踪”事件

## 角色层
- 主角缺陷是否被触发？示例：第4章面对上级选择沉默

## 语言层
- 是否有空泛形容词？示例：删除“非常、特别”等词
```

## 问题日志模板

```markdown
# 问题日志
| 位置 | 问题 | 原因 | 替代方案 |
|---|---|---|---|
| 第3章 | 信息解释过多 | 破坏节奏 | 改为角色行动揭示 |
| 第7章 | 角色反转突兀 | 铺垫不足 | 增加第5章埋伏笔 |
```

## 投稿/格式检查表

```markdown
# 投稿/格式检查表
- 查询信是否包含简介、故事梗概、作者信息？示例：三段结构完成
- 格式是否符合行业规范？示例：双倍行距、页码齐全
```
