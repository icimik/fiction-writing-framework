# 模板_发布前最终核对单

## 使用说明

- 用于阶段 9 发布准备 / 校样准备。
- 原则：不再改正文结构，只做发布层确认、校样层确认与口径统一。
- 若 Editor 在阶段 8 未明确给出“通过”或“停止正文大修，转入发布准备”，不得直接使用本模板。

## 模板

```markdown
# 发布前最终核对单

## 使用说明

- 适用对象：
- 用途：正式发布前做最后一遍人工核对
- 原则：不再改正文结构，只做发布层确认、校样层确认与口径统一

## 一. 正文定稿确认

- [ ] 确认全文为当前发布版正文，不再继续开启新一轮句面重写
- [ ] 抽读卷首、卷尾和终章，确认起落点稳定
- [ ] 抽读高风险章节，确认收束仍保持既定气质
- [ ] 确认短引文、便签、短信、提示文字的呈现口径符合当前正文规范

## 二. 平台页信息确认

- [ ] 书名、类型、题材、关键词、目标读者、平台分类已统一
- [ ] 内部工作名不出现在对外平台页正文
- [ ] 平台页简介版本已定，不混用多档简介
- [ ] 若平台字数有限，已确定压缩版简介

## 三. 文案资产确认

- [ ] 推荐文案包已定稿
- [ ] 分平台社交文案已定稿
- [ ] 分章节推广文案已定稿
- [ ] 对外文案未回退为概念化、宣传腔、翻译腔

## 四. 口径统一确认

- [ ] 对外定位与正文一致
- [ ] 不误包装类型
- [ ] 不额外补“翻身式结尾”解释
- [ ] 不用站位口号覆盖作品本身

## 五. 卷后资产确认

- [ ] 后记已准备
- [ ] 作者手记已准备
- [ ] 若平台不适合放完整版本，已确定压缩策略

## 六. 排版与校样确认

- [ ] 只处理长段分段与版心适配，不改句意
- [ ] 目录、章名、卷名一致
- [ ] 无多余空行、异常标点或格式错位
- [ ] 引号、书名号、顿号等口径统一

## 七. 发布动作顺序建议

1. 先确定平台页简介版本与分类标签
2. 再确定首发平台配套文案
3. 再确定首周社交推广节奏
4. 再从章节推广文案中选择推送内容
5. 最后发布后记或作者手记节选

## 八. 最终判断线

满足以下四项即可视为可发布：

- [ ] 正文不再继续改
- [ ] 发布页简介已选定
- [ ] 对外文案已统一口径
- [ ] 首发渠道的实际发布文本已从现有文档中拷定，不再临场重写
```
