# 文档模板集

说明：本文件提供框架内最小模板集合。更丰富模板（反馈、审稿、数据统计）请引用 `framework/references/process/workflow.md` 的 4.5 节与 `framework/03-templates/模板_共享审阅块.md`。

## 模板使用顺序

1. 先填立项简报与世界观模板。
2. 再填角色与分卷模板。
3. 生成前三章后使用样章评审模板。
4. 进入连载后固定使用日志、反馈、复盘模板。

## 1. 立项简报模板

```markdown
# 立项简报

- 项目名：
- 类型/题材：
- 目标读者：
- 平台：
- 预计体量：
- 更新节奏：
- 核心卖点：
- 核心前提句：
- 风格约束：
- 禁用项：
```
