# 模板_项目README

## 使用说明

- 用于项目根目录 `README.md`。
- 目标不是重复框架全文，而是把通用模板落到当前项目的真实目录、真实阶段和真实下一步上。
- 项目统一使用 `README.md` 作为入口文件。
