# 项目标准模板（Project Template）

每个项目统一采用以下目录结构：

```text
项目名/
  00-intake/                  # 输入与立项来源（idea/设定原稿）
  01-brief/                   # 创作简报、边界与目标
  02-research/                # 市场、竞品、题材调研
  03-foundation/              # 世界观、角色、阵营等基础设定
  04-outline/                 # 分卷大纲、章节节拍
  05-rules/                   # 项目专属创作规则与复用规则映射
  06-analysis-research/       # 读者画像、定位分析、策略分析
  07-writing/
    samples/                  # 前三章样稿
    chapters/                 # 正式章节
  08-operations/
    logs/                     # 工作日志/创作手记
    feedback/                 # 作者/读者/编辑反馈汇总
    retrospectives/           # 周/月/N章/分卷复盘
    change-log/               # 变更记录
  09-assets/                  # 插图、设定图、附加资源
  99-archive/                 # 项目内部历史归档
    import-YYYYMMDD/          # 同世界观外部导入批次（按日期追溯）
```

## 统一执行流程

1. 在 `00-intake/` 放入 idea 或初始设定。
2. 在 `01-brief/` 明确受众、平台、体量、更新节奏。
3. 在 `03-foundation/` 完善世界观、角色、阵营。
4. 在 `05-rules/` 建立项目规则（并引用复用规则）。
5. 在 `06-analysis-research/` 完成读者画像与市场匹配分析。
6. 在 `04-outline/` 完成分卷大纲与前三章节拍。
7. 在 `07-writing/samples/` 产出前三章样稿。
8. 在 `08-operations/feedback/` 汇总反馈并生成调整动作。
9. 在 `07-writing/chapters/` 进入后续章节生产。
10. 全程记录 `08-operations/logs/`，并按周期写复盘。

## 短篇小说集补充结构

适用：设定集驱动短篇集、同世界观多地区短篇集。

建议补充：
- `04-outline/短篇矩阵_*.md`
- `04-outline/短篇扩展大纲_*.md`
- `06-analysis-research/篇章反雷同审阅与改稿清单_*.md`
- `06-analysis-research/导入资产融合评估_*.md`
- `08-operations/feedback/reviews-YYYYMMDD/`

执行原则：
- `07-writing/samples/` 保留未转正样稿。
- `07-writing/chapters/` 只放已转正的正式篇章。
- 导入短篇在完成融合评估前，一律先放 `99-archive/import-YYYYMMDD/`。
