# 模板_Reviewer评审单

## 使用说明

- 由 Reviewer 在每轮稿件评审后填写。
- 评审必须基于 `review-rubric 的 references/checklists.md` 与 Rulebook 分册。
- 每条问题必须可定位、可复核、可执行。
- 适用于单章、分卷、整书终稿和发布资产包评审。

## Reviewer评审单

```markdown

- 轮次：第___轮
- 评审范围：第___章-第___章 / 第___卷 / 整书终稿 / 发布资产包 / 设定版本___ / 大纲版本___
- 评审时间：YYYY-MM-DD
```
