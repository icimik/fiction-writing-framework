# 审阅

流程层模块。输出定性反馈 + 量化评分 + 达标结论。

## 约束读取

开始前必须读取：`review-rubric`。
按需读取：`narrative-knowledge`、`chinese-writing-constraints`、`intimacy-levels`。

## 执行步骤

### 1. 收稿

确认：作品名、材料类型、题材、当前阶段、作者诉求、是否需要 MBTI 评审。

### 2. 文学编辑

判断内部质量：主题（靠行为后果还是口号）、人物（行动者还是容器）、情节（有无推进/升级/选择/结局）、叙事（视角/信息释放）、文风（有无翻译腔）。

### 3. 出版编辑

判断外部面向：题材定位、卖点、读者画像、传播风险、出版潜力。

### 4. MBTI 读者（可选）

调用 `review-rubric` 的 references/personas/，从不同阅读偏好给出反馈和评分。

### 5. 量化汇总

各角色得分 → 维度平均分 → 分歧分析。

### 6. 达标判定

P0（硬失败）/ P1（明显影响）/ P2（可优化）。pass ≥ 80，conditional 65-79，fail < 65。

### 7. 输出

- 整体结论
- 修订优先级（P0/P1/P2）
- MBTI 分角色反馈（可选）
- 量化评分汇总
- 达标判定

模板见 `templates` 的 references/审阅/。
