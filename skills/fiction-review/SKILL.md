# 系统审阅

## 定位

本 skill 是操作层模块，负责对虚构文学作品进行系统化审阅，输出定性反馈 + 量化评分 + 达标结论。

## 执行流程

### 1. 读取约束

- **必读**：`review-rubric`（评分体系与 MBTI personas）
- **按需**：`narrative-knowledge`（需要叙事理论支撑时）
- **按需**：`chinese-writing-constraints`（评估中文表达质量时）
- **按需**：`intimacy-levels`（检查亲密内容是否合规时）

### 2. 收稿与确认

确认：作品名、材料类型、题材、当前阶段、作者本轮重点诉求、是否需要 MBTI 读者评审与量化评分。

### 3. 文学编辑初审

判断文本内部质量：
- 主题（是否有效表达，是否靠口号而非行为后果）
- 人物（是否是行动者而非观点容器）
- 情节（是否有推进、升级、选择、结局）
- 叙事（视角、时间线、信息释放是否合理）
- 文风（是否服务叙事，是否有翻译腔）
- 修订优先级排序

### 4. 出版编辑初审

判断作品的外部面向：
- 题材定位与市场匹配
- 卖点提炼
- 目标读者画像
- 传播风险
- 连载/出版潜力

### 5. MBTI 读者评审（可选）

调用 `review-rubric` 的 references/personas/ 下的读者角色，从不同阅读偏好给出：
- 总体感受
- 喜欢与不满点
- 是否继续阅读
- 分维度评分

### 6. 量化汇总

- 各角色得分
- 通用维度平均分
- 分歧最大的维度
- 高低分角色差异原因

### 7. 达标判定

- P0 率（硬约束失败、格式无效、设定冲突）
- pass / conditional / fail 判定
- 整书级：是否达到可发布、可停改状态

### 8. 整合输出

最终审稿至少输出：
- 整体审稿结论
- 修订优先级建议（P0/P1/P2）
- 必要时的 MBTI 分角色反馈
- 量化评分汇总
- 达标判定

## 产出要求

每次正式审阅至少应沉淀：
- 审稿文档
- 必要时的 MBTI 评审文档
- 必要时的结构化修订清单
