# 改写

流程层模块。对已有文本执行改写、精修、中文重塑。

## 约束读取

开始前必须读取：`chinese-writing-constraints`。

## 改写模式

**逐字逐句精修**（用户明确要求时）：只改表达，不改结构/因果/章尾钩子。按反模式清单逐句检查。

**整章重写**（默认）：从叙事任务出发重写，不参考原文句式。执行三阶段检查。

**中文重塑**（条件触发）：翻译腔严重时使用。保留情节骨架，完全重写语言层。

## 执行步骤

1. 确认改写模式和范围
2. 读取 `chinese-writing-constraints` 的 references/checking-process.md
3. 确认本章叙事任务（发生什么事，不是表达什么概念）
4. 执行改写
5. 整章回读确认连贯
6. 说明改了什么、为什么改、保留了什么

## 精修方法

详见 `chinese-writing-constraints` 的 references/refine-methods.md。

## 硬约束

- 不擅自改动结构、因果、人物关系、章尾钩子
- 整章重写，不做局部替换
- 问题降到校样级时停止大修
