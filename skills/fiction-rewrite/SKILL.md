# 改写与精修

## 定位

本 skill 是操作层模块，负责对已有虚构文学文本进行改写、精修和中文重塑。

## 执行流程

### 1. 读取约束

- **必读**：`chinese-writing-constraints`（中文生成约束，不可跳过）
- **按需**：`narrative-knowledge`（需要结构分析时）
- **按需**：`narrative-knowledge` 的 references/editing-review.md（审阅与改稿方法论）

### 2. 改写模式

**逐字逐句精修**（用户明确要求时）：
- 只改表达，不改结构、因果、人物关系与章尾钩子
- 按中文生成约束的反模式清单逐句检查
- 保持原作的情节推进和情绪节奏

**整章重写**（默认模式）：
- 从叙事任务出发重写，不参考原文句式
- 确认"这一章要完成什么叙事任务"，再动笔
- 执行中文生成约束的三阶段检查

**中文重塑**（条件触发）：
- 当原文翻译腔严重、需要从底层重构中文表达时使用
- 保留情节骨架和角色行为，完全重写语言层

### 3. 硬约束

- 未经明确要求，不擅自改动结构、因果链、角色关系、时间顺序、信息释放顺序和章尾钩子
- 任何正文改写必须整章重写或按整章回读，不做局部查找替换式修补
- 不创建 `.bak`、`_old` 等正文副本
- 当问题已从正文级下降到校样级、发布口径级时，必须停止正文大修

### 4. 输出要求

- 改写后必须整章回读，确认整体连贯
- 说明改写了什么、为什么改、保留了什么
- 若涉及结构变动，必须单独说明并获得确认
