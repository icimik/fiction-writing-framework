# 三阶段检查流程

生成中文正文时必须执行的检查流程。反模式清单见 `anti-patterns.md`，精修方法见 `refine-methods.md`。

## 生成前（每段）

1. 这一段的叙事任务是什么？（回答"发生什么事"，不是"表达什么概念"）
2. 这一段由谁感知、谁行动？
3. 入段方式是否和前一段雷同？如果是，必须换一种

## 生成中（每句）

1. 当前句子的主语是不是抽象名词？→ 如果是，换回人或物
2. 当前句子是不是在解释而不是在叙述？→ 如果是，先回到动作或场面
3. 当前句子的连接词是否超过两个？→ 如果是，拆句
4. 当前句子的动词前面是否堆了三个以上修饰语？→ 如果是，拆到动词后面或另起分句
5. 当前句子是不是可以删掉一半仍然成立？→ 如果是，删

## 生成后（每段、每章）

每段回查：
1. 朗读这一段，像中文小说还是像翻译文学？
2. 把段中所有"使得""导致""意味着""表明""令人"标出来，尝试全部消除
3. 段尾是不是情绪或概念总结句？→ 如果是，换成物件、时间或动作

每章回查：
1. 全章是否存在三段以上的段落结构雷同？
2. 全章的句子开头是否存在连续雷同？
3. 全章的对白是否区分了角色身份和当下状态？
4. 全章读完后的直觉：这是一个中文故事，还是一篇翻译稿？

## 快速自检 8 问

生成任何中文正文后，至少过以下 8 问：

1. 这段里有没有抽象名词当主语的句子？→ 全换回人或物
2. 有没有"让/使/令 + 感到"的句式？→ 全换回具体场面
3. 有没有连续两个以上连接词的句子？→ 拆句
4. 有没有段尾总结句？→ 换成物件或动作
5. 有没有连续三段结构雷同？→ 打散
6. 有没有书面腔对白？→ 按角色和场合重写
7. 有没有 `anti-patterns.md` 伪高级句式清单里的句式？→ 逐条检查消除
8. 朗读全段，听起来像中文小说还是翻译文学？→ 如果后者，整段重写

## 与项目级文档的配合

执行优先级：
1. `anti-patterns.md` 的模式识别和替换策略 → 所有项目生效
2. 项目 `STYLEGUIDE.md` 的题材和角色定制 → 项目内生效
3. 角色 `SOUL.md` 的声线定制 → 角色出场时生效
4. 三份 `现代汉语_*.md` → 追溯规则依据时使用

配合方式：
1. 生成正文前，先读本文档，再读项目 STYLEGUIDE，再读当前 POV 角色的 SOUL
2. 项目 STYLEGUIDE 中关于中文表达的规则，应是本框架的题材化延伸，不重新发明规则
3. 若项目发现了未覆盖的新翻译腔模式，应在复盘时回写到 `anti-patterns.md`
