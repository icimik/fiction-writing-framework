# 精修与重塑方法

阶段 7（整书精修）和阶段 7b（中文重塑）的操作方法。检查流程见 `checking-process.md`，反模式见 `anti-patterns.md`。

## 为什么"在原文上改"容易失效

用同一个 LLM 精修它自己生成的翻译腔，往往只是把"翻译腔 A"改成"翻译腔 B"。

机制：
- LLM 在精修模式下会被原文的句法骨架锚定（anchoring），只能做表面词汇替换
- "修改这段话"内含了"保留原文结构"的隐含假设，而正是原文结构才是问题所在
- 反复在同一段上执行多轮标准精修不会收敛，只会浮动

判断标准：一段文本经过一轮"给 LLM 原文让它改"后朗读仍不自然，必须立即切换到重述法。

## 阶段 7 默认方法

- **重述法**是默认精修方式
- **分层法**用于高风险章节
- **锚文本法**在有项目语言参考时每批附带使用
- **删减法**在整书回读时执行

详见 `project-governance` 的 references/stage-details.md 阶段 7。

## 四种方法详解

以下四种方法按优先级排序。前三种互斥（对同一段选一种），删减法可叠加。

### 方法 1：重述法（优先级最高）

核心操作：不给 LLM 原文，只给叙事任务，让它重新写。

步骤：
1. 用一两句话写清当前段落的叙事任务：谁在哪里做什么，发生了什么，结果是什么
2. 用具体事件而非抽象概括描述任务
   - 正确："他在药房柜台前站了五分钟，最后把止痛药放回去。"
   - 错误："展现贫困对日常生活的影响。"
3. 让 LLM 从叙事任务出发写这一段，不提供原文
4. 写完后检查：新段落是否保留了原段必须携带的信息点（人名、时间、物件、因果关系）

为什么有效：拔掉原文，LLM 的句法锚定就消失了，它会从中文的叙事习惯出发组织句子。

### 方法 2：锚文本法

核心操作：给 LLM 一段达标的中文小说段落作为语感样本，让它按这个语感重写目标段落。

步骤：
1. 找一段达标的中文小说段落（自己写的或别人的）
2. 放在 prompt 开头，说"请按这个语感重写下面的段落"
3. 再给出要精修的段落

材料来源：优先从项目 `09-assets/项目写作语言参考_*.md` 抽取；若未建立，从本项目写得好的章节抽取；若整书都不达标，从同题材中文小说抽取。

为什么有效：LLM 对具体文本的模仿力远强于对抽象规则的执行力。200 字的锚文本比 2000 行规则文档更能校准语感。

### 方法 3：分层法

核心操作：不一次精修全部，而是分三轮，每轮只处理一种问题。

步骤：
1. 第一轮：只改对白——按角色身份、体力状态和当下场景重写，不动叙述
2. 第二轮：只改段首和段尾——段首是翻译腔高发位置，段尾是情绪标签高发区
3. 第三轮：只删——不改写，只删除冗余连接词、情绪标签和总结句

为什么有效：每轮注意力集中在一种问题上，输出质量比"通读改全部"高得多。

### 方法 4：删减法（可与其他方法叠加）

核心操作：对段落只做减法，不做改写。

步骤：
1. 删所有可删连接词（"然而""因此""与此同时""尽管如此"），看句意是否仍然成立
2. 删所有"使得""导致""意味着""让他感到""令人"，强制补具体动作
3. 删段尾总结句
4. 删所有"某种""无法言喻""难以形容"等偷懒词

为什么有效：删不会引入新的翻译腔。改会。

## 操作约束

1. 一段文本经过一轮标准精修后仍不自然，不得再试一轮相同操作，必须升级
2. 不得连续用标准精修处理同一段超过两次
3. 优先级：重述法 > 锚文本法 > 分层法，删减法可叠加
4. 重述法写完后必须核对原段的信息点，确保人名、时间、物件、因果关系未丢失
5. 锚文本的语感应与本项目的题材和气质匹配
6. 修复方法的使用必须记录在工作日志和变更记录中
