# 评审标准与评分体系

## 定位

本 skill 是知识层模块，为 fiction-review 提供评审方法论和评分工具。

## 内容

### 评分体系

- 通用评分轴（task_adherence, constraint_adherence, narrative_coherence, character_voice, setting_consistency, language_quality, creative_effect, editability）
- 作品级附加轴（overall_unity, reader_payoff）
- 优先级判定：P0（硬失败）/ P1（明显影响）/ P2（可优化）
- 达标阈值：pass ≥ 80，conditional 65-79，fail < 65

详细评分规则见 `references/scoring-rubric.md`。

### MBTI 读者角色

8 种读者 persona，从不同阅读偏好出发给出反馈：
- INTJ / INTP / INFJ / INFP（分析型/直觉型）
- ENTJ / ENTP / ISFJ / ESFP（外向型/感觉型）

每种 persona 包含：阅读偏好、敏感维度、评分倾向、典型反馈模式。

详见 `references/personas/` 目录下各 persona 文件。
