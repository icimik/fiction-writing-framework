# 虚构类文学创作技术指导
更新时间: 2026-03-05

虚构创作的意义不仅是讲故事，更是把人、规则与选择放进同一个可验证的系统里。本指南把“灵感”转化为“可执行流程”，覆盖从世界观、角色、情节、叙事到修辞与编辑审阅的完整链条。它既适合零基础入门，也适合已在连载或改写中的作者与编辑，用来稳定结构、发现漏洞、提高交付质量。所有模块都以工具与模板形式呈现，也可直接作为 AI Agent 的可用技能进行创作、分析与审阅。

## 覆盖范围
- 作品类型: 传统文学、网络文学、轻小说、长篇连载、剧作、动漫、互动叙事。
- 写作环节: 设定、人物、结构、叙事、语言、修订与审阅。
- 目标结果: 形成可交付的世界观、角色、情节、叙事策略与修订记录。

## 适配对象与阶段
- 新手: 从“最小工具链”开始，先完成主产出物再进入细化。
- 创作者: 用“实施记录+验证清单”把构思落地为可检验文本。
- 编辑: 用“执行标准+清单示例”定位问题并组织修复。
- 创意探索中: 先用高概念锚点与角色卡建立边界。
- 已有大纲与设定: 直接进入情节结构与叙事策略模块。
- 已产出样章: 走修辞与编辑审阅，补齐逻辑链与风格一致性。
- 连载中段: 用结构诊断与伏笔回收复盘节奏与张力。
- 瓶颈期: 先做问题日志，再用执行标准逐条回收。
- 全文改写: 先结构再语言，按三层修订清单重建。

## 快速上手指南
1. 选定类型或基调，建立高概念锚点。
2. 用角色卡与关系矩阵锁定主冲突。
3. 写出三幕大纲与关键转折点。
4. 用时间线表检查因果顺序。
5. 选定叙事视角并填视角信息表。
6. 写第一章并用三层修订清单改写。

## 创作基本流程
1. 设定: 确定世界规则与故事边界。
2. 角色: 定义人物动机与关系网络。
3. 情节: 搭建因果链与关键转折点。
4. 叙事: 选择视角与时间结构。
5. 语言: 控制风格与表达密度。
6. 修订: 用清单验收，结构先行再润色。

## 使用路径
- 轻量路径: 高概念锚点 → 角色卡 → 三幕大纲 → 第一章。
- 标准路径: 规则清单 → 角色卡 → 情节大纲 → 叙事策略 → 修辞优化 → 编辑审阅。
- 编辑路径: 执行标准 → 清单示例 → 问题日志 → 修复记录。
- AI 路径: 输入目标与限制 → 选择模块与模板 → 生成产出物 → 依据执行标准自动检查。

- 情节大纲与关键转折点

- 修辞风格指南
- 编辑审阅记录

## 行动步骤
1. 选择当前阶段对应的模块。
2. 复制对应的“可直接复用的文档片段”模板。
3. 生成“输出样张”级别的可交付内容。
4. 用“执行标准”逐条验收。
5. 进入下一阶段或回收问题。

## 栏目定义与使用方式
- 要点: 原则与核心技法的解释区块，用来理解为什么这样做。
- 作者建议: 作者侧执行提醒，告诉你写的时候怎么落地。
- 编辑建议: 编辑侧验收提醒，告诉你验收时看什么。
- 执行标准: 最低可验收标准，避免只写概念不落地。
- 参考片段: 统一世界观小说中的对应情节定位，用于对照理解。
- 可直接复用的文档片段: 空模板，用于真实填表与记录。
- 输出样张: 模板的填写示例，用于快速对齐完成度。
- 清单示例: 检查点与示例，帮助审阅与修订定位问题。
- 跨媒介变体与小模板: 剧作、动漫、互动叙事的适配入口。
