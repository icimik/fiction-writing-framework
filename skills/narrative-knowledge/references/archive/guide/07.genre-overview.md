# 类型适配总览
更新时间: 2026-03-04

## 如何使用本章
- 先选“类型”，再按“工具链”走流程，最后用“模板”生成可交付产出物。
- 每个类型都给出“工具链 + 产出物 + 可复用模板 + 场景示例”，可直接套用到长篇小说写作。
- 如果你是混合类型写作，按主类型走全流程，副类型只保留关键工具。

## 类型总览
| 类型 | 读者期待 | 核心矛盾 | 推荐工具链 |
|---|---|---|---|
| 悬疑/推理 | 真相揭示与逻辑闭环 | 真相与误导的对抗 | 因果链表 → 伏笔回收表 → 转折点清单 |
| 爱情/情感 | 情感递进与关系转折 | 亲密需求与现实阻力 | 角色卡 → 关系矩阵 → 角色弧线表 |
| 科幻 | 设定新颖且自洽 | 科技/制度与人性的冲突 | 世界观总纲 → 规则清单 → 信息释放计划 |
| 奇幻 | 规则神秘且可验证 | 信念/使命与代价 | 世界观总纲 → 魔法规则表 → 任务链表 |
| 历史/架空 | 史实质感与分歧合理性 | 变动代价与权力博弈 | 分歧点推演 → 背史时间线 → 设定验证清单 |
| 犯罪/都市 | 动机可信与伦理张力 | 正义与利益冲突 | 角色卡 → 证据链表 → 转折点清单 |
| 成长/校园 | 心理转折与身份确立 | 自我需求与外部期待 | 角色弧线表 → 关键事件表 → 关系矩阵 |
| 冒险/史诗 | 危机升级与旅程回报 | 团队目标与世界危机 | 旅程路线图 → 阶段目标表 → 反派压力表 |
| 现实主义/社会 | 社会议题与人物命运 | 结构性困境与个人选择 | 议题清单 → 场景验证表 → 角色卡 |
| 连载/网络文学 | 节奏稳定与持续钩子 | 长线悬念与单元高潮 | 情节大纲 → 节奏比例表 → 小高潮清单 |

## 1. 悬疑/推理
### 类型目标与风险
目标是“合理但意外”的真相揭示。风险在于逻辑漏洞、线索失衡与回收失败。

### 工具链
1. 因果链表
2. 伏笔-回收表
3. 转折点清单

### 产出物清单
- 真相与表象对照表
- 线索矩阵
- 回收节点时间表

### 模板
```markdown
# 悬疑类型策划简表
- 核心谜题: 雨夜失踪案中最关键的证物为何消失
- 表面真相: 受害者自导自演以逃避债务
- 真相: 证物被同伴销毁以掩盖过失致死
- 主要视角与信息限制: 第一人称调查员，无法进入嫌疑人私域
- 关键线索: CL-01 车票残角 / CL-02 港口监控 / CL-03 临时钥匙
- 误导线索: CL-04 债务转账记录
- 回收节点: 第7章揭示CL-04误导，第11章集中回收CL-01与CL-03
```

### 场景示例段落
第七章里，调查员终于得到那张被雨水泡烂的车票残角。它指向一条不存在的凌晨列车，似乎证明了受害者的自导自演。然而第十一章里，港口监控显示“列车”其实是码头夜班的调度车，车票是同伴伪造的通行凭证，误导线索被完整回收。

### 常见反模式
- 只靠巧合推动真相揭示，读者无法复盘因果链。
- 线索堆砌但没有回收节点，造成“线索通胀”。

## 2. 爱情/情感
### 类型目标与风险
目标是让关系在冲突中递进，并完成情感弧线。风险是冲突单薄或转折不可信。

### 工具链
1. 角色卡
2. 关系矩阵
3. 角色弧线表

### 产出物清单
- 关系张力图
- 情感转折点表
- 价值观差异清单

### 模板
```markdown
# 爱情主线策划卡
- 情感主题: 亲密关系中的信任与独立
- 关系起点: 互相吸引但价值观对立
- 核心冲突: 自由职业 vs 稳定体制
- 关键转折: 第6章误解分手，第11章共同选择
- 终局形态: 关系继续但保持边界
- 弧线分段: 1-5章建立好感 / 6-9章冲突升级 / 10-15章重建信任
```

### 场景示例段落
第六章，女主拒绝了男主的求助请求，选择独自完成项目。表面上是工作独立，实则是回避依赖的恐惧。第十一章，男主主动划清边界并提供支持，关系从“谁更需要谁”转向“如何共同选择”，情感弧线完成一次关键转折。

### 常见反模式
- 关系进展靠“误会拖延”，缺乏真实价值观冲突。
- 用外部事件强行推动和解，缺乏内心变化铺垫。

## 3. 科幻
### 类型目标与风险
目标是用明确规则构建新世界，并让设定驱动冲突。风险是设定随意改动与解释过度。

### 工具链
1. 世界观总纲
2. 规则清单与验证表
3. 信息释放计划

### 产出物清单
- 核心科技设定表
- 社会影响矩阵
- 设定验证场景清单

### 模板
```markdown
# 科幻设定验证卡
- 核心科技: 记忆可被合法交易
- 规则限制: 记忆交易不可逆，非法交易会造成精神断层
- 社会影响: 记忆贫富分化，黑市兴起
- 验证场景: 第3章主角出售童年记忆；第8章遭遇精神断层
- 设定冲突: 法规保护 vs 个人自由
```

### 场景示例段落
第三章，主角在交易大厅卖掉童年记忆换取治疗费用，换来的却是对亲人的陌生感。第八章，黑市交易导致精神断层，设定的代价被直接验证，并推动主角质疑制度的合法性。

### 常见反模式
- 设定只用于装饰，与情节推进无关。
- 设定解释过度，削弱人物行动与紧迫感。

## 4. 奇幻
### 类型目标与风险
目标是让神秘规则可验证，并让代价与信念推动情节。风险在于“任意魔法”导致冲突失效。

### 工具链
1. 世界观总纲
2. 魔法规则表
3. 任务链表

### 产出物清单
- 魔法规则清单
- 禁忌与代价表
- 主线任务链

### 模板
```markdown
# 奇幻规则与任务卡
- 魔法来源: 以记忆为代价借来神灵之力
- 使用限制: 每次施法遗忘一段人际关系
- 禁忌规则: 不能对亲属施法
- 主线任务: 找回被封印的誓言之书
- 关键代价场景: 第6章忘记导师姓名
```

### 场景示例段落
第六章，主角为了救队友施法，却在战后忘记导师姓名。这一代价触发了禁忌规则的阴影，也迫使主角重新评估任务的意义，任务链被推进且代价真实可见。

### 常见反模式
- 魔法规则随情节需要临时改变。
- 代价只在口头上存在，从不影响人物选择。

## 5. 历史/架空
### 类型目标与风险
目标是让分歧点推演可信，并与历史质感保持一致。风险是“便利的历史”和缺乏因果链。

### 工具链
1. 分歧点推演
2. 背史时间线
3. 设定验证清单

### 产出物清单
- 分歧点推演表
- 历史因果链
- 史实对照表

### 模板
```markdown
# 架空历史分歧表
- 分歧事件: 某次战役未能成功援军
- 推演结果: 地区割据提前十年形成
- 关键影响: 贸易路线改变，主城经济衰退
- 体现章节: 第1章序幕与第5章商会冲突
- 史实对照: 保留同年代技术与制度基础
```

### 场景示例段落
第一章序幕通过一封未能送达的战报揭示分歧事件，第五章商会争夺航道权力，具体呈现贸易路线改变对主城的影响，历史因果链可追溯且一致。

### 常见反模式
- 只改时间线，不改社会结构与技术细节。
- 用“主角天赋”替代历史推演逻辑。

## 6. 犯罪/都市
### 类型目标与风险
目标是动机可信、证据链完整，同时保留伦理张力。风险是“神探式猜谜”与动机空洞。

### 工具链
1. 角色卡（动机/需求）
2. 证据链表
3. 转折点清单

### 产出物清单
- 犯罪动机卡
- 证据链验证表
- 伦理冲突记录表

### 模板
```markdown
# 犯罪调查链
- 犯罪动机: 保护家人免受债务威胁
- 证据起点: 第2章匿名录像
- 证据链推进: 录像编号与银行流水关联
- 伦理冲突: 证据涉及无辜者隐私
- 关键转折: 第8章选择公开证据导致二次伤害
```

### 场景示例段落
第八章里，主角决定公开匿名录像，虽然揭开了真相，却导致无辜者名誉受损。动机与伦理冲突共同作用，案件推进同时加深人物代价。

### 常见反模式
- 证据链跳跃，重要证据突然出现。
- 犯罪动机仅为“邪恶”，缺乏现实压力。

## 7. 成长/校园
### 类型目标与风险
目标是清晰的心理转折与身份确立。风险是“事件堆砌”而无内在变化。

### 工具链
1. 角色弧线表
2. 关键事件表
3. 关系矩阵

### 产出物清单
- 成长阶段时间轴
- 触发事件清单
- 关系变化记录表

### 模板
```markdown
# 成长弧线规划卡
- 初始缺口: 只追求成绩，缺乏自我认同
- 触发事件: 第4章竞赛失败
- 关键导师: 图书馆老师
- 价值观转折: 第9章拒绝替考
- 终局形态: 找到自我节奏与目标
```

### 场景示例段落
第九章里，主角拒绝替考邀请，失去了一次“捷径”，却第一次以自己的价值观做选择。这一决定成为成长弧线的关键节点，后续关系矩阵随之重构。

### 常见反模式
- 成长仅靠“成功事件”，没有失败与反思。
- 角色变化突兀，缺乏逐步内化过程。

## 8. 冒险/史诗
### 类型目标与风险
目标是阶段性危机与旅程回报并行。风险是旅程缺乏阶段目标与情节重复。

### 工具链
1. 旅程路线图
2. 阶段目标表
3. 反派压力表

### 产出物清单
- 旅程阶段表
- 团队职能卡
- 危机升级曲线

### 模板
```markdown
# 史诗旅程规划表
- 旅程起点: 失陷的边境城
- 阶段目标1: 夺回航道
- 阶段目标2: 联盟谈判
- 反派压力: 每阶段加重封锁
- 终极回报: 归还象征国运的古印
```

### 场景示例段落
在第六章，团队夺回航道，但反派同时切断补给线，使阶段胜利转化为新困境。旅程路线图保证每个阶段有回报又有升级压力。

### 常见反模式
- 旅程每一站都像“重复关卡”，没有递进。
- 反派压力缺席，冒险缺少紧迫感。

## 9. 现实主义/社会
### 类型目标与风险
目标是结构性议题与人物命运结合。风险是议题口号化或角色工具化。

### 工具链
1. 议题清单
2. 场景验证表
3. 角色卡

### 产出物清单
- 议题-场景映射表
- 利益冲突图
- 现实细节清单

### 模板
```markdown
# 议题落地验证表
- 核心议题: 小城医疗资源不足
- 具体场景: 第3章排队挂号冲突
- 角色利益: 主角需要手术名额，护士受限于制度
- 叙事目标: 让制度压力具体化
- 后续影响: 主角转向自费选择，家庭矛盾升级
```

### 场景示例段落
第三章的挂号大厅里，主角被迫与护士争执。制度并非“恶人”，却让每个人都无能为力。场景验证表把议题落到具体行动与选择上。

### 常见反模式
- 用角色说教代替情节推进。
- 议题只在背景板出现，人物选择不受影响。

## 10. 连载/网络文学
### 类型目标与风险
目标是稳定节奏与持续悬念。风险是“掉线式更新”和高潮稀薄。

### 工具链
1. 情节大纲
2. 节奏比例表
3. 小高潮清单

### 产出物清单
- 章节节奏表
- 长线钩子清单
- 小高潮兑现表

### 模板
```markdown
# 连载节奏规划卡
- 长线钩子: 反派真实身份隐藏到第40章
- 小高潮密度: 每3章一次强转折
- 章节末钩子: 第11章揭示失踪者归来
- 兑现规则: 次章必须提供新信息
- 读者反馈记录: 每10章复盘一次节奏
```

### 场景示例段落
第十一章结尾揭示失踪者归来，第十二章立即给出其动机与新问题，节奏不“拖泥带水”，读者被持续推进到下一章。

### 常见反模式
- 章节末只用“断章”制造虚假紧张。
- 长线钩子拖到失去新信息的价值。
