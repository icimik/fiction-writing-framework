# 情节

## 理论锚点

1. **埃格里前提法则**：故事的灵魂是一句带有对抗性、指向终极价值的真理，贯穿全文的精神主线。前提公式 = 主角核心特质 + 核心行动 + 极端对抗 + 终极价值。所有情节、角色、冲突都必须为证明或证伪这个前提服务。

2. **亚里士多德"净化"(Catharsis)**：文学的终极价值是通过情节铺垫实现读者情绪的积压与释放。动笔前必须明确情绪净化目标：商业文主打爽感宣泄，文学向主打悲悯共情。

3. **亚里士多德"突转与发现"**：高潮转折不是机械降神，而是主角"发现"残酷真相，引发命运"突转"。高潮前必设"发现"环节。

4. **坎贝尔"英雄之旅" + 灵魂黑夜**：高潮来临前，主角陷入极致绝境，旧面具彻底破碎。每卷/全文必设灵魂黑夜，落点是"失去一切 + 直面创伤 + 内心觉醒"。

## 结构选型矩阵

详细实施方法见 `narrative-knowledge 的 references/structure-toolbox.md`。这里保留的是“选哪种结构”的判断，不重复展开每种结构的完整操作手册。

1. **默认骨架**
- 长篇连载、日常系、慢生活、关系推进型作品：默认用 **丹·哈蒙故事圈** 作为单元骨架。
- 需要更强宏观控制时：用 **三幕结构** 定整书/分卷大骨架，再用故事圈拆单元。

2. **节奏与场景校验**
- 章节或场景节奏不稳时：用 **拯救猫咪节拍表** 或 **Story Grid 五大诫命** 校验打点和场景功能。
- 需要检查“这一场到底有没有推进”时：优先看 **Story Grid**。

3. **长篇规划**
- 需要从结局倒推、管理伏笔回收时：用 **七点式结构**。
- 需要把一句话或段落扩成卷纲/章纲时：用 **雪花写作法**。

4. **人物与对手**
- 需要强化人物缺陷、对手网络、道德启示时：用 **特鲁比 22 步**。
- 需要构建复杂人物群像与价值冲突时：优先参考 **巴赫金复调** 与特鲁比，不要只靠单一反派。

5. **题材调性**
- 成长、史诗、冒险：可借 **英雄之旅** 的结构意识，但不必机械照搬。
- 悲剧、坠落、反派弧光：可借 **弗赖塔格金字塔**。
- 日常、留白、低冲突、观察型段落：可借 **起承转合** 的“转”与“合”来做意外和余味。
- 高冲突、强追读、副线推进：可借 **费希特曲线** 填充第二幕或故事圈的 Search 区段。

6. **组合原则**
- 一次只设定一个主结构，最多叠加一个辅助结构和一个场景校验器。
- 不能为了套结构强行改人物行为；结构永远服从题材、人物和阶段目标。
- 对本框架默认写法，优先采用：**故事圈 + 单章任务 + 场景校验**。

## 可执行条款

1. 主线目标必须在开篇明确，且每 3-5 章可观察推进一次。
2. 每章必须有：核心冲突、推进目标、章末钩子。
3. 结构必须选型并固定（如三幕式/分卷式），禁止中途无理由切换。
4. 伏笔必须登记：埋设位置、回收节点、回收状态。
5. 大纲变更必须走联动更新：人设、设定、伏笔同步校正。

## 脚手架

1. 定核心主线：1 句话写死主角终极目标。
2. 搭卷章结构：按"铺垫 → 小高潮 → 发现真相 → 灵魂黑夜 → 觉醒大高潮 → 卷末钩子"排布。
3. 埋情绪/爽点：贴合受众心理，规划爽点与共情点。
4. 设伏笔闭环：标注伏笔埋设与回收节点。
5. 划大纲红线：明确可微调/严禁改动项。
6. 控节奏配比：按 7 分剧情 + 2 分日常 + 1 分情感。

## 产出要求

- `分卷大纲.md`
- `单章节拍表.md`
- `伏笔-回收表.md`
- `冲突矩阵.md`

## 检查项

- [ ] 主线与支线关系清晰，支线能反哺主线。
- [ ] 冲突升级存在梯度，不平推。
- [ ] 高潮前存在"发现/突转"机制。
- [ ] 章末钩子不重复同质。
- [ ] 伏笔回收率达到计划值。
- [ ] 核心卖点与前提不超过 2 个，清晰凝练且自带冲突感。
- [ ] 明确受众与情绪净化目标。

## 避坑清单

- 不写无意义水剧情，日常情节必服务主线。
- 不为反转而反转，反转贴合逻辑。
- 不随意加支线，支线必反哺主线。
- 章末/卷末必留钩子。
- 严禁无规划改动大纲。
- 不堆砌多核心亮点，聚焦 1-2 个核心记忆点。

## 失败判定

- 大量水情节不推动主线。
- 反转无铺垫、仅为反转。
- 大纲更新后未同步关联文档。
