# 模板_篇章反雷同审阅单

## 使用说明

- 适用于短篇小说集、多地区同世界观篇章组、导入整编后的横向复审。
- 关注的是“结构性雷同”与“阅读体感趋同”，不是单纯语句重复。
- 审阅结论应直接落到改名、改开篇、改信息释放、整章重写或篇目回退。
