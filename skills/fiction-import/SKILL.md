# 导入

流程层模块。将外部资产与现有项目融合。

## 约束读取

开始前必须读取：`chinese-writing-constraints`（导入内容可能有翻译腔）。
按需读取：`narrative-knowledge`（评估世界观一致性）。

## 执行步骤

1. 批次归档导入源到 `99-archive/import-YYYYMMDD/`
2. 资产评估：类型识别、一致性检查、冲突识别。模板见 `templates` 的 references/导入/。
3. 裁决策略：
   - 直接归并：完全兼容，直接纳入
   - 重写归并：有可用内核但需改写
   - 基线统一：覆盖现有设定，需更新基线
   - 拒绝融合：冲突严重，不纳入
4. 统一落库并联动更新

## 硬约束

- 导入资产必须经过评估，不可直接复制
- 融合后必须检查设定一致性
- 所有决策必须可追溯

## 准出标准

- 融合评估报告已写入 `06-analysis-research/`
- 每项导入资产已标注处理结论（归并/重写/归档/拒绝）
- 设定一致性体检通过（核心设定、时间线、命名规则无冲突）
- 联动更新已完成（变更记录、工作日志）
