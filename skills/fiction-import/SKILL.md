# 外部资产导入

## 定位

本 skill 是操作层模块，负责将外部导入的虚构文学资产与现有项目进行融合。

## 适用场景

- 导入外部同世界观的设定文档
- 导入外部章节或片段并融入现有项目
- 对导入资产做融合评估
- 重写归并与基线统一

## 执行流程

### 1. 读取约束

- **必读**：`chinese-writing-constraints`（导入内容可能有翻译腔，需要重塑）
- **按需**：`narrative-knowledge`（评估世界观一致性时）

### 2. 资产评估

按 `references/模板_导入资产融合评估.md` 执行：
- 资产类型识别（设定/章节/角色/世界观）
- 与现有项目的一致性检查
- 冲突点识别
- 融合可行性判断

### 3. 融合策略

- **直接归并**：资产与现有设定完全兼容，直接纳入
- **重写归并**：资产有可用内核但表达/设定有差异，重写后纳入
- **基线统一**：导入资产覆盖或补充现有设定，需要更新基线文档
- **拒绝融合**：资产与现有设定冲突严重，不纳入

### 4. 输出要求

- 融合评估报告
- 冲突点清单与解决方案
- 更新后的设定/章节文档
- 变更记录

## 硬约束

- 导入资产必须经过评估，不可直接复制粘贴到项目中
- 融合后必须检查设定一致性
- 融合过程中的所有决策必须可追溯
