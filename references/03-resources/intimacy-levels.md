# 亲密描写分级指南

## 0. 文档定位

- 本文件是框架级的通用亲密描写分级指南，默认不绑定任何具体作品、角色、时代、平台或世界观。
- 它的作用是把“写到什么程度算合适”拆成可执行层级，减少作者反复试写、反复修正尺度的成本。
- 本指南只讨论叙事强度，不替代题材边界、平台规范或法律边界。
- 文中的场面示例都已做去定制化处理，使用时应替换成你的具体人物关系和场景条件。

## 1. 基本原则

- 先看场景的叙事任务，再看人物关系，再看亲密强度。
- 先剥离作品专属信息，再判断等级。角色名、时代背景、职业头衔、地名和物件设定都不影响等级本身。
- 同一场戏可以混用相邻等级，但不要在同一段里来回跳。
- 越接近高强度等级，越要清楚“为什么此刻需要这一级别”，而不是只追求刺激。
- 亲密描写的目标可以是推进关系、确认归属、制造悬念、完成和解、表现失控，也可以只是让读者感到两个人正在靠近。
- 当某一段已经逼近 L5，但作者仍希望维持非露骨口径时，应优先尝试把该段重写为 L4，而不是继续往前推。
- L4 重写的核心，不是删掉情绪，而是把明确性动作改写成贴近、压迫、呼吸、余温、视线和身体反应。

## 2. 分级总表

### L0 点到为止

- 目标感受：有关系，但不点火。
- 典型表现：
  - 递茶、扶手、让座、替人挡风。
  - 指尖轻碰一下就收回。
  - 眼神停留，但马上移开。
- 适配场景：
  - 初识
  - 试探前段
  - 公开场合或礼节约束很强的地方
- 适配关系：
  - 主从初见
  - 还没确认心意的两人
  - 必须克制的关系
- 叙事方式：
  - 轻描
  - 借物传情
  - 用动作代替表白
- 风险：
  - 太淡，读者感受不到推进。

### L1 轻暧昧

- 目标感受：开始有热度，但还在表层。
- 典型表现：
  - 替人整理衣领、拢发、按住袖口。
  - 肩并肩坐得很近。
  - 说话时故意压低声音，靠近耳边。
  - 眼神里有试探，但没有直接推进。
- 适配场景：
  - 刚确认彼此有兴趣
  - 需要保留体面的私下相处
  - 夜里、屏风后、门边、灯下
- 适配关系：
  - 初次靠近
  - 还在观察对方的人
  - 权力差明显、但尚未越界的关系
- 叙事方式：
  - 以细节堆温度
  - 让读者先感到“在靠近”
  - 不急着让身体完全贴上
- 风险：
  - 容易写成只是在“站得近”，缺少欲望。

### L2 明显肉感

- 目标感受：关系开始发热，身体距离变成叙事核心。
- 典型表现：
  - 接吻变密。
  - 手扣腰、按肩、捏下巴、顶膝、压榻。
  - 衣袖滑落、衣襟散开、发丝乱掉。
  - 呼吸乱、声音哑、手指发颤。
  - 体温、汗意、皮肤热度被写出来。
- 适配场景：
  - 关系明确转向
  - 章节中段的情绪升压
  - 关门、榻边、灯下、车内、卧室等私密空间
- 适配关系：
  - 已确认彼此有欲望
  - 互相试探到可以贴身
  - 带权力差、占有欲或依赖感的关系
- 叙事方式：
  - 连续动作推进
  - 一层层加压，不要急停
  - 用体温和呼吸替代解释
- 风险：
  - 如果只堆动作，不写反应，会像动作说明书。

### L3 强肉感

- 目标感受：接近临界点，读者能清楚感到“再往前一步就要进入下一层”。
- 典型表现：
  - 反复贴近、分开、再贴近。
  - 亲吻不止停在唇上，会往颈侧、耳边、下颌延伸。
  - 人被压在床上、门边、墙边时，身体反应更明显。
  - 事后余温、呼吸未平、衣料凌乱要写足。
- 适配场景：
  - 卷末钩子前
  - 关系突破点
  - 争宠、占有、确认归属感的段落
- 适配关系：
  - 高位克制型角色
  - 会主动推进关系的角色
  - 有控制欲、依赖感、占有欲的关系
- 叙事方式：
  - 先推强度，再在阈值处收住
  - 事后用整理衣襟、递水、沉默和回避来补足余韵
  - 让场面“停下来”时仍然有热度
- 风险：
  - 容易误判成要直接写过程；本级仍不写性交动作和性器官。

### L4 完整非露骨

- 目标感受：亲密推进可以完整展开，事件前后都能写足，但不正面写生殖器或明确性行为过程。
- 典型表现：
  - 事前铺垫、贴身动作、脱衣/褪衣、压迫、反应、喘息、颤抖、汗意、体温、事后整理都可以完整写。
  - 可以写下意识并紧双腿、脚尖绷直、膝盖收住、指节发白、呼吸发浅这类身体反应。
  - 可以写胸部、乳头、手指、接吻、贴身、肌肤相贴、十指紧扣、呼吸交错、衣料摩擦、裸肩、裸背、锁骨、腰线、膝侧、颈侧等身体感。
  - 可以写读者明确知道“这里发生了亲密事件”，但不把明确性行为过程写穿。
  - 可用切景、余波、隔门声响、灯火变化、事后状态回收。
- 适配场景：
  - 关系已经稳定到需要确认占有、依附或承诺
  - 单章要完成一次高强度亲密推进
  - 卷末或章节中段需要把感情钉死
- 适配关系：
  - 长线绑定关系
  - 已有信任、欲望和占有欲的组合
  - 需要把身体推进与权力推进绑在一起的关系
- 叙事方式：
  - 过程完整，但不写穿
  - 感官细节拉满
  - 用事后整理和视线变化收束
- 风险：
  - 容易误写成 L5；一旦开始正面写生殖器或明确性行为过程，就越线了。

### L5 露骨色情

- 定义：
  - 直接描写生殖器，或正面描写插入、抽送、口交等明确性行为过程。
- 适用场景：
  - 仅限明确接受此类内容的情色作品。
- 适配读者：
  - 以直接性描写为主要阅读需求的读者。
- 叙事方式：
  - 直写过程。
- 本指南态度：
  - 不作为通用默认写法。
  - 如果作品要使用此级别，应当在题材、平台和读者预期上先明确。
  - 若正文没有正面写生殖器、插入、抽送、口交等明确性行为过程，默认仍归入 L4。

## 3. 创作规避规则

- 如果草稿在推进中发现自己正在逼近 L5，但项目目标并不要求露骨写法，优先回退一步，把该段重写成 L4。
- 回写 L4 时，优先保留场面张力、角色欲望、肢体压迫与事后余韵，删除或淡出明确性器官和明确性行为过程。
- 这类回写不是失败修补，而是正常的创作规避流程，应该在写前、写中和写后检查中反复执行。

## 4. 各等级对应的读者感受

- L0 和 L1 主要给广谱读者，重点是好嗑、克制、能往下追。
- L2 和 L3 面向更吃关系推进的读者，重点是“终于有肉感了”。
- L4 主要服务已经接受这条关系线、希望看到高强度亲密完整展开的读者。
- L5 属于更直接的情色阅读取向，不适合作为默认指南口径。

## 5. 各等级对应的关系状态

### 初识型

- 推荐等级：L0-L1
- 关系特征：刚认识、刚试探、不能太快越界。

### 试探型

- 推荐等级：L1-L2
- 关系特征：已经有意向，但还要留后路。

### 绑定型

- 推荐等级：L2-L3
- 关系特征：已经确认彼此会影响对方的情绪和行动。

### 终局型

- 推荐等级：L3-L4
- 关系特征：亲密不只是亲密，而是权力、归属和选择的结果。

## 6. 场景适配建议

- 白天公共场景：优先 L0-L1，压住，不急推。
- 夜间私密场景：可到 L2-L3，但要先有情绪铺垫。
- 床边、灯下、关门后的空间：最适合 L2-L4。
- 情节收口、关系确认：可用 L3-L4。
- 随时可能进人、会被窥看的场合：不建议高于 L1。

## 7. 推荐叙事手法

- 用物件推进：门、灯、帘、茶杯、衣带、发簪、手帕。
- 用感官推进：呼吸、温度、汗意、指尖、颈侧、衣料摩擦。
- 用动作推进：靠近、按住、拢衣、捋袖、压住、回抱、拉回。
- 用结果推进：发热、发抖、沉默、回避、重新整理衣襟。
- 用留白推进：在最关键的阈值前切走，但不要把前后的变化写断。

## 8. 场面实例

### L0 示例

她把茶盏放到案上，指尖碰了一下对方的袖口，立刻收回去。对方没看茶，只看了她一眼，手指在杯沿上停了半拍。

### L1 示例

她替对方把散掉的发丝别到耳后，声音压得很低。对方站在帘边没动，等她把手收回去，才慢慢抬眼。

### L2 示例

她把对方逼到榻边，手按在腰侧不放。对方呼吸一乱，抬膝顶住她，衣袖跟着滑下来，露出一截发热的手臂。

### L3 示例

两个人在狭小的私密空间里贴得太近，呼吸乱成一团。衣襟散到肩头，灯火被压得很低。等她们分开时，指尖还在抖，杯里的茶已经凉了半盏。

### L4 示例

门合上后，房间里只剩急促的呼吸和衣料一次次擦过床面的细响。她把外衫褪到臂弯，肩背露出一片被灯火烫得发亮的白，另一人抬手按住她后腰，掌心里全是热汗。等灯芯跳过一回，屋里静下来时，茶已经凉了，衣带也被重新系好，只剩两个人都没说出口的那口气还压在胸口。

她被对方压得往后靠了一点，膝盖下意识并紧，脚尖也绷了起来，手指却还是扣在那截衣料上，没有真的躲开。对方没有再逼，只把额头抵过来，呼吸一下一下落在她耳侧，像是故意把这点发热的反应一点点看尽。

## 10. 写前检查清单

- [ ] 这一场戏要完成什么，是推进关系、确认归属、制造悬念，还是完成和解。
- [ ] 角色关系现在走到哪一层，能不能支撑当前等级。
- [ ] 场景是否私密，是否允许更高一级的亲密强度。
- [ ] 本段戏是否需要“完整展开”还是只需要“点到为止”。
- [ ] 这一段是否会因为太淡而失去肉感，或者因为太满而失去控制。
- [ ] 是否已经明确不该写的边界，例如性交动作和性器官。

## 11. 写中检查清单

- [ ] 有没有只写动作没写反应。
- [ ] 有没有只写情绪没写身体。
- [ ] 有没有把同一种动作重复写了太多次。
- [ ] 有没有在同一段里反复跳等级。
- [ ] 有没有把“完整非露骨”误写成“露骨过程”。
- [ ] 有没有把场景写得太空，缺少呼吸、温度和触感。

## 12. 写后检查清单

- [ ] 读起来是否能判断这一场戏用了哪个等级。
- [ ] 亲密推进是否完整，还是中间断裂得太厉害。
- [ ] 事后余温、衣料整理、视线变化是否写到了。
- [ ] 有没有越过明确性行为过程和性器官描写的边界。
- [ ] 是否能顺着这一场戏看出关系有没有更进一步。
- [ ] 是否需要把当前等级再提升或再下调一级。

## 13. 默认口径

- 默认正文一般使用 L1-L3。
- 如果作品需要完整展开亲密推进但不写生殖器或明确性行为过程，可使用 L4。
- 一旦写作目标变成直接性描写，应当先重新确认作品定位、平台和读者预期，再决定是否使用 L5。
