# 亲密描写分级指南

## 0. 文档定位

- 本文件是框架级的通用亲密描写分级指南，默认不绑定任何具体作品、角色、时代、平台或世界观。
- 它的作用是把"写到什么程度算合适"拆成可执行层级，减少作者反复试写、反复修正尺度的成本。
- 本指南只讨论叙事强度，不替代题材边界、平台规范或法律边界。
- 文中的场面示例都已做去定制化处理，使用时应替换成你的具体人物关系和场景条件。

## 1. 基本原则

- 先看场景的叙事任务，再看人物关系，再看亲密强度。
- 先剥离作品专属信息，再判断等级。角色名、时代背景、职业头衔、地名和物件设定都不影响等级本身。
- 同一场戏可以混用相邻等级，但不要在同一段里来回跳。
- 越接近高强度等级，越要清楚"为什么此刻需要这一级别"，而不是只追求刺激。
- 亲密描写的目标可以是推进关系、确认归属、制造悬念、完成和解、表现失控，也可以只是让读者感到两个人正在靠近。
- 当某一段已经逼近 L5，但作者仍希望维持非露骨口径时，应优先尝试把该段重写为 L4，而不是继续往前推。
- L4 重写的核心，不是删掉情绪，而是把明确性动作改写成贴近、压迫、呼吸、余温、视线和身体反应。

## 2. 分级总表

### L0 点到为止

- 目标感受：有关系，但不点火。
- 典型表现：
  - 递茶、扶手、让座、替人挡风。
  - 指尖轻碰一下就收回。
  - 眼神停留，但马上移开。
- 适配场景：
  - 初识
  - 试探前段
  - 公开场合或礼节约束很强的地方
- 适配关系：
  - 主从初见
  - 还没确认心意的两人
  - 必须克制的关系
- 叙事方式：
  - 轻描
  - 借物传情
  - 用动作代替表白
- 风险：
  - 太淡，读者感受不到推进。

### L1 轻暧昧

- 目标感受：开始有热度，但还在表层。
- 典型表现：
  - 替人整理衣领、拢发、按住袖口。
  - 肩并肩坐得很近。
  - 说话时故意压低声音，靠近耳边。
  - 眼神里有试探，但没有直接推进。
- 适配场景：
  - 刚确认彼此有兴趣
  - 需要保留体面的私下相处
  - 夜里、屏风后、门边、灯下
- 适配关系：
  - 初次靠近
  - 还在观察对方的人
  - 权力差明显、但尚未越界的关系
- 叙事方式：
  - 以细节堆温度
  - 让读者先感到"在靠近"
  - 不急着让身体完全贴上
- 风险：
  - 容易写成只是在"站得近"，缺少欲望。

### L2 明显肉感

- 目标感受：关系开始发热，身体距离变成叙事核心。
- 典型表现：
  - 接吻变密。
  - 手扣腰、按肩、捏下巴、顶膝、压榻。
  - 衣袖滑落、衣襟散开、发丝乱掉。
  - 呼吸乱、声音哑、手指发颤。
  - 体温、汗意、皮肤热度被写出来。
- 适配场景：
  - 关系明确转向
  - 章节中段的情绪升压
  - 关门、榻边、灯下、车内、卧室等私密空间
- 适配关系：
  - 已确认彼此有欲望
  - 互相试探到可以贴身
  - 带权力差、占有欲或依赖感的关系
- 叙事方式：
  - 连续动作推进
  - 一层层加压，不要急停
  - 用体温和呼吸替代解释
- 风险：
  - 如果只堆动作，不写反应，会像动作说明书。

### L3 强肉感

- 目标感受：接近临界点，读者能清楚感到"再往前一步就要进入下一层"。
- 典型表现：
  - 反复贴近、分开、再贴近。
  - 亲吻不止停在唇上，会往颈侧、耳边、下颌延伸。
  - 人被压在床上、门边、墙边时，身体反应更明显。
  - 事后余温、呼吸未平、衣料凌乱要写足。
- 适配场景：
  - 卷末钩子前
  - 关系突破点
  - 争宠、占有、确认归属感的段落
- 适配关系：
  - 高位克制型角色
  - 会主动推进关系的角色
  - 有控制欲、依赖感、占有欲的关系
- 叙事方式：
  - 先推强度，再在阈值处收住
  - 事后用整理衣襟、递水、沉默和回避来补足余韵
  - 让场面"停下来"时仍然有热度
- 风险：
  - 容易误判成要直接写过程；本级仍不写性交动作和性器官。

### L4 完整非露骨

- 目标感受：亲密推进可以完整展开，事件前后都能写足，但不正面写生殖器或明确性行为过程。脱衣、肌肤相贴、强烈身体反应（脚尖绷直、颤抖）、非直接高潮与体液。
- 典型表现：
  - 事前铺垫、贴身动作、脱衣/褪衣、压迫、反应、喘息、颤抖、汗意、体温、事后整理都可以完整写。
  - 可以写下意识并紧双腿、脚尖绷直、膝盖收住、指节发白、呼吸发浅这类身体反应。
  - 可以写胸部、乳头、手指、接吻、贴身、肌肤相贴、十指紧扣、呼吸交错、衣料摩擦、裸肩、裸背、锁骨、腰线、膝侧、颈侧等身体感。
  - 可以写读者明确知道"这里发生了亲密事件"，但不把明确性行为过程写穿。
  - 。
- **L4/L5 关键边界**：
  - **高潮**：L4允许强烈身体反应（弓起、绷直、痉挛、虚脱抽动）；L5需直接描写生殖器收缩、喷溅等。
  - **体液**：L4允许汗水、混合湿意；L5允许精液、爱液的具体流动与细节。
  - **性癖道具**（绳艺、蜡烛等）：L3以上即可出现，L4可详细描写过程与感受，L5则结合露骨性行为。
- 适配场景：
  - 关系已经稳定到需要确认占有、依附或承诺
  - 单章要完成一次高强度亲密推进
  - 卷末或章节中段需要把感情钉死
- 适配关系：
  - 长线绑定关系
  - 已有信任、欲望和占有欲的组合
  - 需要把身体推进与权力推进绑在一起的关系
- 叙事方式：
  - 过程完整，但不写穿
  - 感官细节拉满
  - 用事后整理和视线变化收束
- 风险：
  - 容易误写成 L5；一旦开始正面写生殖器或明确性行为过程，就越线了。

### L5 露骨色情

- 定义：
  - 正面明确描写生殖器名称、插入/抽送/口交、生殖器指向的高潮与体液。
- 适用场景：
  - 重度情色向、重度性癖，仅限明确接受此类内容的情色作品。
- 适配读者：
  - 以直接性描写为主要阅读需求的读者。
- 叙事方式：
  - 直写过程。
- 本指南态度：
  - 不作为通用默认写法。
  - 如果作品要使用此级别，应当在题材、平台和读者预期上先明确。
  - 若正文没有正面写生殖器、插入、抽送、口交等明确性行为过程，默认仍归入 L4。

## 3. 创作规避规则

- 如果草稿在推进中发现自己正在逼近 L5，但项目目标并不要求露骨写法，优先回退一步，把该段重写成 L4。
- 回写 L4 时，优先保留场面张力、角色欲望、肢体压迫与事后余韵，删除或淡出明确性器官和明确性行为过程。
- 这类回写不是失败修补，而是正常的创作规避流程，应该在写前、写中和写后检查中反复执行。

## 4. 各等级对应的读者感受

- L0 和 L1 主要给广谱读者，重点是好嗑、克制、能往下追。
- L2 和 L3 面向更吃关系推进的读者，重点是"终于有肉感了"。
- L4 主要服务已经接受这条关系线、希望看到高强度亲密完整展开的读者。
- L5 属于更直接的情色阅读取向，不适合作为默认指南口径。

## 5. 各等级对应的关系状态

### 初识型

- 推荐等级：L0-L1
- 关系特征：刚认识、刚试探、不能太快越界。

### 试探型

- 推荐等级：L1-L2
- 关系特征：已经有意向，但还要留后路。

### 绑定型

- 推荐等级：L2-L3
- 关系特征：已经确认彼此会影响对方的情绪和行动。

### 终局型

- 推荐等级：L3-L4
- 关系特征：亲密不只是亲密，而是权力、归属和选择的结果。

## 6. 场景适配建议

- 白天公共场景：优先 L0-L1，压住，不急推。
- 夜间私密场景：可到 L2-L3，但要先有情绪铺垫。
- 床边、灯下、关门后的空间：最适合 L2-L4。
- 情节收口、关系确认：可用 L3-L4。
- 随时可能进人、会被窥看的场合：不建议高于 L1。

## 7. 推荐叙事手法

- 用物件推进：门、灯、帘、茶杯、衣带、发簪、手帕。
- 用感官推进：呼吸、温度、汗意、指尖、颈侧、衣料摩擦。
- 用动作推进：靠近、按住、拢衣、捋袖、压住、回抱、拉回。
- 用结果推进：发热、发抖、沉默、回避、重新整理衣襟。
- 用留白推进：在最关键的阈值前切走，但不要把前后的变化写断。

## 9. 扩展：关系类型与特殊形态

### 9.1 异性关系子类型

**寝取（NTR）**
- 核心张力：罪恶感与快感的交织、权力反转
- L1-L2：原配与第三者的眼神交锋、桌下隐秘触碰
- L3-L4：在原配在场时的隐秘身体接触、被发现的风险
- 叙事重点：心理层面的背叛感，而非单纯的身体描写
- 示例：丈夫去洗手间的三分钟里，她把手指放在他大腿内侧，指尖画圈。他没有推开，但视线飘向洗手间方向。

### 9.2 同性关系

**叙事差异**：
- 社会压力更大，私密空间更封闭
- 眼神和呼吸的权重高于直接身体接触
- 禁忌感更强

**分级适配**：
- L0-L1：共用耳机、整理领带/围巾、挡酒
- L2-L3：更衣室/试衣间独处、手指交扣时的对视、颈侧嗅闻
- L4：类似异性L4，强调"被发现的风险"

**示例（男男L3）**：
健身房淋浴间，水声掩盖呼吸。他把他推到瓷砖墙上，手掌按在胸口，感受到心跳快得不正常。没有接吻，只是额头相抵，水汽在两人之间凝结。

**示例（女女L3）**：
试衣间帘子没拉严。她从背后帮她拉裙子拉链，手指停在蝴蝶骨上。镜子里两人视线相遇，手指没有离开。

### 9.3 纯爱关系

**核心**：情感推进优先于身体推进

**节奏**：
- L0-L1阶段拉长，强调"差一点"的张力
- L2以上必须有情感确认（告白、危机共渡）
- 身体接触后必须回到情感层面

**示例**：
他没有立刻亲她，先问："我可以吗？"她点头，但眼泪先掉下来。他吻掉她的眼泪，然后才是嘴唇。

### 9.4 D/s（支配/臣服）关系

**核心机制**：
- 通过语言命令、身体位置、视线控制建立权力差
- 身体接触是权力的具象化
- Aftercare（事后安抚）是必须的叙事环节

| 等级 | D/s表现 | 身体表达 | 性癖元素 |
|------|---------|---------|---------|
| L1 | 语言命令 | "看着我""跪下" | - |
| L2 | 位置控制 | 扣腕、按头、跪姿 | - |
| L3 | 轻度惩罚 + 道具引入 | 咬、拍打、轻绑 | 绳艺初步束缚、少量蜡烛滴蜡 |
| L4 | 中重度控制 + 非露骨高潮 | 完整绳艺、蒙眼、强烈身体反应 | 复杂绳艺、蜡烛大面积使用、蒙眼下的感官剥夺 |
| L5 | 重度调教 + 露骨性过程 | 绳艺束缚下插入、明确生殖器描写 | 束缚状态下的深度抽送、滴蜡同时进行性行为 |

**关键元素**：
- 语言："谁允许你动的？""再说一遍"
- 位置：站立者vs跪坐者
- 节奏：支配者决定何时开始、何时结束

**示例（D/s L3）**：
她站在他面前，手指抬起他的下巴，强迫他抬头。"谁允许你动的？"他没有回答，喉结滚动。她笑了，手指从下巴滑到颈侧，轻轻掐住。

**Aftercare示例**：
她松开他的手腕，替他揉着发红的地方。他靠在她肩膀上，呼吸平稳下来。"还好吗？"她问。他点头，手指攥着她的衣角。

### 9.5 心理扭曲关系

**类型**：斯德哥尔摩、煤气灯操控、病态占有欲

**叙事策略**：
- 身体接触与心理操控同步
- 亲密行为作为控制手段
- 受害者身体反应与心理抗拒的矛盾

| 等级 | 表现 |
|------|------|
| L2-L3 | 占有标记（咬痕、掐痕）、控制式亲密 |
| L4 | 用非露骨高潮强化"身体无法抗拒"的矛盾 |
| L5 | 通过露骨性行为完成极端占有（射入、标记式高潮） |

**示例（病态占有L3）**：
他咬她的肩膀，不是调情，是留下印记。"这样别人就知道你是我的。"她疼得发抖，但不敢推开。他的手指插进她头发里，强迫她抬头。"说你是我的。"

**注意**：避免美化虐待关系。

### 9.6 其他重度性癖适配

**绳艺/束缚play**：
- L3：初步束缚 + 挣扎中的感官描写
- L4：复杂绳艺 + 无力状态下的强烈身体高潮反应（绷直、颤抖、虚脱）
- L5：束缚状态下的深度插入、无法逃脱的露骨高潮过程

**蜡烛play / 温度play**：
- L3：少量滴蜡 + 疼痛与快感交织
- L4：大面积滴蜡 + 结合高潮的身体颤抖与敏感反应
- L5：滴蜡同时进行性行为 + 露骨高潮

**羞耻play / 暴露癖**：
- L3：言语羞辱 + 半暴露
- L4：镜子前或危险场所的强烈身体反应与高潮
- L5：公开/半公开下的明确性行为 + 高潮细节

**NTR/寝取**（补充）：
- L3：背德风险下的强烈贴近、亲吻延伸、事后余温与罪恶感
- L4：背德高潮（强烈身体反应，如颤抖、脚尖绷直、意识恍惚），可写"在原配可能出现的情况下达到顶点"的心理与生理冲突，但不直接描写性器官
- L5：偷情时的露骨性过程（明确插入、抽送、高潮喷溅），并强化与原配关系的对比背德感

**通用原则**：性癖元素应服务于人物性格、关系冲突和心理变化。即使在L5，也应注重情感深度，而非单纯机械描写。

## 10. 扩展：心理层次与特殊形态

### 10.1 性幻想

**功能**：展示未被满足的欲望、为实际行动铺垫

**写法**：
- 明确标注是幻想（"他想象……"）
- 幻想内容可以比实际更极端
- 幻想结束后的落差感

**示例**：
会议中，他看着对面女人的嘴唇，突然想象她跪在他办公桌下的样子。这个念头来得太快，他端起水杯掩饰走神。水温正好，但他觉得喉咙发干。

### 10.2 言语挑逗（Dirty Talk）

| 等级 | 表现 |
|------|------|
| L1 | 双关语、暗示（"今晚你很精神"） |
| L2-L3 | 具体描述想做的事 |
| L4 | 命令式（"现在摸自己"） |

**示例（L2言语挑逗）**：
餐厅里，她在桌下脱掉一只高跟鞋，脚尖沿着他的小腿往上滑。他握住水杯的手紧了紧。她俯身，嘴唇几乎贴着他耳朵："你硬了。"然后坐回去，继续切牛排。

### 10.3 文爱（语C）

**定义**：通过文字进行的虚拟亲密互动

**用法**：异地恋、网络相识、试探阶段的安全距离

**示例**：
手机屏幕亮了一下："现在把手放在……"她盯着那行字，手指悬在屏幕上方，心跳快得不正常。窗外有人在走路，她下意识地拉上了窗帘，然后才回复："然后呢？"

## 12. 扩展：反模式化写作

### 12.1 常见陷阱

**陷阱一：动作复读机**
- ❌ 每一场都用同样序列（手指交握→额头抵住→亲吻→离开）
- ✅ 车内用顶膝、压肩；门边用按墙、扣腕；榻上用拢发、捋袖

**陷阱二：情绪空洞化**
- ❌ 只写"呼吸乱了""身体颤抖"
- ✅ 指尖发颤、膝盖并紧、脚尖绷直、指节发白

**陷阱三：事后格式化**
- ❌ 每次都是"整理衣服→离开→关门"
- ✅ 递水、沉默对视、回避视线、重新点灯、突然哭

### 12.2 动作多样化矩阵

| 阶段 | 方案A（强势） | 方案B（试探） | 方案C（被动） | 方案D（意外） |
|------|--------------|--------------|--------------|--------------|
| 开场 | 直接推到墙上 | 指尖画圈试探 | 抓住衣角不松手 | 意外跌倒压住 |
| 升温 | 扣手腕、咬颈侧 | 鼻尖蹭、呼吸交错 | 攀肩膀、埋颈窝 | 慌乱中嘴唇碰到 |
| 高潮 | 顶开膝盖、按头 | 手指插进头发里 | 主动解扣子 | 停住、对视、再靠近 |
| 收尾 | 命令整理衣服 | 替对方拢头发 | 手指还扣着不松 | 突然有人敲门 |

### 12.3 去模式化检查清单

- [ ] 本场戏的动作序列是否和上一场不同
- [ ] 是否有至少一个独特的身体细节（不是通用的"呼吸乱了"）
- [ ] 事后收尾是否和上一场不同
- [ ] 场景是否有特定性（不是通用的"门边"）
- [ ] 权力关系是否通过身体位置表达
- [ ] 是否有至少一个物件参与

## 13. 去定制化检查清单

- [ ] 文档里的角色名、称谓、身份头衔、地名、时代标签是否已经删掉或替换成通用占位信息。
- [ ] 示例是否只保留"关系状态 + 场景条件 + 动作强度"，而没有保留某个作品专属设定。
- [ ] 这一版是否可以直接迁移到别的题材，且不需要改动分级逻辑。
- [ ] 是否已经把"这个作品能写什么"与"这个等级本身怎么定义"分开。
- [ ] 是否保留了可复用的抽象词，而不是只剩定制化名词。

## 14. 写前检查清单

- [ ] 这一场戏要完成什么，是推进关系、确认归属、制造悬念，还是完成和解。
- [ ] 角色关系现在走到哪一层，能不能支撑当前等级。
- [ ] 场景是否私密，是否允许更高一级的亲密强度。
- [ ] 本段戏是否需要"完整展开"还是只需要"点到为止"。
- [ ] 这一段是否会因为太淡而失去肉感，或者因为太满而失去控制。
- [ ] 是否已经明确不该写的边界，例如性交动作和性器官。

## 15. 写中检查清单

- [ ] 有没有只写动作没写反应。
- [ ] 有没有只写情绪没写身体。
- [ ] 有没有把同一种动作重复写了太多次。
- [ ] 有没有在同一段里反复跳等级。
- [ ] 有没有把"完整非露骨"误写成"露骨过程"。
- [ ] 有没有把场景写得太空，缺少呼吸、温度和触感。

## 16. 写后检查清单

- [ ] 读起来是否能判断这一场戏用了哪个等级。
- [ ] 亲密推进是否完整，还是中间断裂得太厉害。
- [ ] 事后余温、衣料整理、视线变化是否写到了。
- [ ] 有没有越过明确性行为过程和性器官描写的边界。
- [ ] 是否能顺着这一场戏看出关系有没有更进一步。
- [ ] 是否需要把当前等级再提升或再下调一级。

## 17. 节奏控制：快、慢、停

### 17.1 何时快

**场景**：
- 久别重逢，压抑已久的欲望爆发
- 权力关系明确，上位者主导节奏
- 危险情境，随时可能被发现

**写法**：
- 连续动作，减少心理描写
- 用短句、逗号、破折号制造急促感
- 省略过渡（直接跳到身体接触，省略对话）

**示例**：
门刚合上，他就把她推到墙上。手扣住她手腕，膝盖顶进她双腿间。她没来得及说话，他的嘴唇已经压下来。

### 17.2 何时慢

**场景**：
- 首次突破，需要确认对方意愿
- 纯爱线，情感重于欲望
- 权力试探，观察对方反应

**写法**：
- 每个动作之间插入感官细节
- 延长犹豫、停顿、对视的时间
- 用长句、分号、省略号制造张力

**示例**：
他的手指停在她的衣领边缘，没有立刻解开。她能感觉到他的呼吸落在她颈侧，一下，又一下。时间变得很慢，慢到她能数清自己的心跳。过了很久，他的手指才动了一下，很轻，像怕碰碎什么。

### 17.3 何时停

**场景**：
- 阈值前（即将越界时停下）
- 被外界打断（电话、敲门）
- 情感反扑（突然哭泣、犹豫）

**写法**：
- 突然的动作停止
- 视线移开、呼吸平复
- 整理衣服、找话题、离开

**示例**：
他的手已经从她衣服下摆伸进去，掌心贴着她腰侧的皮肤。她抖了一下，但没有躲。就在这时，手机响了。不是她的，是他的。铃声很刺耳，像从另一个世界传来的。他的手停住了。过了几秒，他把手抽出来，替她拉好衣服下摆。

## 18. 失败回退：从L5回到L4

### 18.1 何时需要回退

- 草稿写着写着发现接近L5（出现生殖器、插入意图）
- 平台/编辑反馈尺度过大
- 作品定位变化（从成人向转向一般向）

### 18.2 回退策略

**核心原则**：保留情绪张力，替换具体动作

| L5元素 | 回退为L4写法 |
|--------|-------------|
| 直接写阴茎/阴道 | 改为"他""她""那里"或身体部位代称 |
| 插入动作 | 改为"贴近""压迫""身体交缠" |
| 抽送过程 | 改为"呼吸交错""衣料摩擦""身体颤抖" |
| 高潮描写 | 改为"绷直脚尖""手指攥紧""呼吸停滞" |

### 18.3 回退示例

**L5草稿（需回退）**：
他进入她，开始抽送。她呻吟，身体随着他的节奏摆动。

**回退为L4**：
他把她压在床上，身体贴上来。她感觉到他的重量和热度，呼吸一下子乱了。他的嘴唇沿着她的颈侧往下滑，牙齿轻轻咬住她的锁骨。她绷直了脚尖，手指攥紧了床单。

**关键**：
- 不写"进入"，写"贴近""压迫"
- 不写"抽送"，写"呼吸交错""身体颤抖"
- 不写"呻吟"，写"呼吸乱了""手指发颤"

## 19. 跨等级渐变：从L2到L4的渐进写法

### 19.1 为什么需要渐变

- 避免跳跃感（突然从牵手跳到全裸）
- 让读者有心理准备
- 累积情绪张力

### 19.2 渐变路径

**路径A：标准渐进（L2→L3→L4）**

| 阶段 | 动作 | 身体反应 | 感官细节 |
|------|------|---------|---------|
| L2开场 | 接吻、手扣腰 | 呼吸开始乱 | 嘴唇的温度 |
| L2升温 | 衣襟散开、顶膝 | 手指发颤 | 皮肤暴露后的凉意 |
| L3过渡 | 颈侧亲吻、压向墙面 | 膝盖发软 | 瓷砖/墙面的凉意 |
| L3高潮 | 反复贴近分开 | 并紧双腿 | 呼吸交错 |
| L4开场 | 脱衣/褪衣 | 指节发白 | 肌肤相贴的温差 |
| L4高潮 | 身体完全贴合 | 绷直脚尖 | 汗意、体温 |

**路径B：权力型渐进（D/s，L1→L3→L4）**

| 阶段 | 语言 | 动作 | 身体位置 |
|------|------|------|---------|
| L1 | "看着我" | 抬起下巴 | 站立，俯视/仰视 |
| L2 | "不许动" | 扣住手腕 | 推至墙面 |
| L3 | "再说一遍" | 咬颈侧 | 压制，膝盖顶开 |
| L4 | "求我" | 蒙眼/绑缚 | 完全控制 |

## 20. 避免多段同质化

### 20.1 问题：同一场景多个亲密段落重复

**错误示例**：
第一场：门边→手指交握→亲吻→离开
第二场：车内→手指交握→亲吻→离开
第三场：办公室→手指交握→亲吻→离开

### 20.2 解决策略

**策略一：改变开场**
- 第一场：主动方开场（强势推到墙上）
- 第二场：被动方开场（抓住衣角不松手）
- 第三场：意外开场（差点摔倒被接住）

**策略二：改变升温方式**
- 第一场：从嘴唇开始，往下到颈侧
- 第二场：从手指开始，往上到手臂、肩膀
- 第三场：从背后开始，环绕到前面

**策略三：改变高潮动作**
- 第一场：压向墙面，扣手腕
- 第二场：跨坐在腿上，扣后颈
- 第三场：按在桌面上，解扣子

**策略四：改变收尾**
- 第一场：整理衣服，沉默离开
- 第二场：突然电话，中断
- 第三场：有人敲门，慌乱整理

### 20.3 多段差异化检查表

#### 写前
- [ ] 这场戏要完成什么叙事任务？
- [ ] 关系类型是什么（纯爱/交易/D/s/旧情人）？
- [ ] 场景是否私密？是否允许当前等级？
- [ ] 权力动态是什么（谁在上、谁控制）？
- [ ] 是否与上一场戏的模式重复？

#### 写中
- [ ] 动作是否多样化（不只是手指交握）？
- [ ] 是否有具体身体反应（不是笼统的"呼吸乱了"）？
- [ ] 是否有物件参与（门、灯、衣服）？
- [ ] 权力关系是否通过身体位置表达？
- [ ] 是否在同一段里跳等级？

#### 写后
- [ ] 事后场景是否与上一场不同？
- [ ] 是否有过渡到下一幕的钩子？
- [ ] 关系是否有推进？
- [ ] 是否有让读者记住的独特细节？
- [ ] 是否越界（L5或性器官）？

## 21. 角色间亲密关系的长期发展路线规划

### 21.1 示例路线：陌生→D/s→情侣→破裂→陌路→悸动→复合

**阶段1：陌生（L0）**
- 场景：兴趣小组第一次见面
- 身体接触：递东西时指尖相碰
- 心理：好奇、观察、试探

**阶段2：相识（L1）**
- 场景：小组活动后的私下交流
- 身体接触：整理对方衣领、肩并肩坐
- 心理：发现共同点，产生好感

**阶段3：D/s萌芽（L2-L3）**
- 场景：私密空间，权力试探
- 身体接触：命令式用语、位置控制、轻度疼痛
- 心理：探索边界，建立信任，罪恶感与快感交织

**关键转折**：
- 明确D/s规则（安全词、界限）
- 心理层面的依赖形成

**阶段4：性爱关系（L3-L4）**
- 场景：私密空间，情感与欲望交织
- 身体接触：完整亲密，但不写穿
- 心理：身体与权力的双重绑定

**阶段5：成为真正情侣（L2-L4混合）**
- 场景：日常生活+私密空间
- 身体接触：既有D/s的权力游戏，也有平等的亲密
- 心理：从"玩伴"到"伴侣"的身份认同

**关键转折**：
- D/s规则逐渐模糊，情感成分增加
- 出现"如果不玩D/s，我们还剩下什么"的焦虑

**阶段6：感情破裂（L0-L1）**
- 场景：争吵、冷战
- 身体接触：刻意回避，指尖相碰都尴尬
- 心理：失望、愤怒、怀疑

**破裂原因示例**：
- 一方想结束D/s，另一方还想继续
- 权力关系渗透到日常生活，导致窒息
- 第三者介入（新的D/s对象或传统恋爱对象）

**阶段7：形同陌路（L0）**
- 场景：不得不见面的场合（共同朋友、工作）
- 身体接触：完全回避，眼神不接触
- 心理：麻木、自我保护

**阶段8：尴尬场面下的悸动（L1-L2）**
- 场景：封闭空间独处（电梯故障、雨天被困）
- 身体接触：不得不靠近，旧习惯复苏
- 心理：抗拒但身体诚实，回忆涌现

**关键场景**：
雨夜，被困在车里。她浑身湿透，他递毛巾。手指相碰，两人都愣住。他本能地想帮她擦头发，手抬到一半停住。她看着他，眼神复杂。

**阶段9：怀念当初（L0-L3回忆与现实交织）**
- 场景：独处，对话
- 身体接触：犹豫、试探、旧动作重现
- 心理：理解当年的自己，也理解对方

**关键对话**：
"那时候，我以为D/s就是全部。"她说。
"我也是。"他说，"后来才发现，我们只是用权力游戏来掩饰不敢谈感情。"

**阶段10：复合（L2-L4）**
- 场景：私密空间，重新开始
- 身体接触：更成熟的亲密，知道边界在哪里
- 心理：不是回到过去，是建立新的平衡

**复合后的新规则**：
- D/s可以玩，但不是关系的全部
- 有安全词，也有情感沟通的时间
- 知道什么时候是游戏，什么时候是真实

### 21.2 长期路线规划要点

**每个阶段问自己**：
- 这个阶段的身体接触服务于什么叙事任务？
- 权力动态是什么？谁在主导？
- 情绪底色是什么（罪恶、渴望、愤怒、怀念）？
- 如何过渡到下一个阶段（触发事件是什么）？

**避免**：
- 每个阶段都用同样的亲密动作
- 忽略心理变化，只写身体接触
- 阶段跳跃没有触发事件

## 22. 默认口径

- 默认正文一般使用 L1-L3。
- 如果作品需要完整展开亲密推进但不写生殖器或明确性行为过程，可使用 L4。
- 一旦写作目标变成直接性描写，应当先重新确认作品定位、平台和读者预期，再决定是否使用 L5。
- 若正文没有正面写生殖器、插入、抽送、口交等明确性行为过程，默认仍归入 L4。
- 节奏控制、跨等级渐变、避免同质化是写好亲密戏的关键技术，需在写前规划中明确。
