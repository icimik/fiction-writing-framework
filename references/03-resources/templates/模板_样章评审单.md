# 模板_样章评审单

## 使用说明

- 用于前三章或其他试写样章批次的最终裁决文档。
- 本文档不是替代 Reviewer / Reader / Editor 三方产物，而是样章阶段的汇总结论。
- 样章转正前，必须先完成 Reviewer + Reader + Editor 三方审阅，再填写本模板。
