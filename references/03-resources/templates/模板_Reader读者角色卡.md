# 模板_Reader读者角色卡

## 使用说明

- Reader 评审时，至少选 3 个角色卡（建议覆盖男频/女频/轻小说/通勤读者中的至少三类）。
- 每个角色卡独立输出反馈，再由 Editor 汇总共识与冲突。
- 反馈必须包含：喜欢点、劝退点、节奏评价、角色代入、付费/追更意愿、改动建议。
- 整书终稿阶段必须补充：整书连读感受、章节间口径一致性、弃读风险位置、是否适合对外传播。

---

## 角色A：男频系统流读者

- 画像：男性，26岁，互联网工程师
- MBTI：INTJ
- 阅读偏好：系统升级、策略博弈、高信息密度、主线推进快
- 评价倾向：
  - 正向：规则清晰、升级有代价、智斗有反转
  - 负向：情节注水、情绪戏过长、爽点稀释
- 评分权重建议：爽点30% / 主线推进30% / 逻辑严谨25% / 角色15%

## 角色B：女频情感成长读者

- 画像：女性，24岁，品牌运营
- MBTI：INFJ
- 阅读偏好：关系张力、人物成长、情感细节、价值冲突
- 评价倾向：
  - 正向：人物弧光清晰、关系推进自然、关键情绪有层次
  - 负向：角色脸谱化、关系突兀、情绪转折生硬
- 评分权重建议：人物关系35% / 情绪共鸣30% / 叙事节奏20% / 逻辑15%

## 角色C：轻小说校园读者

- 画像：男性，19岁，大学生
- MBTI：ENFP
- 阅读偏好：人设鲜明、对话有梗、节奏轻快、设定新奇
- 评价倾向：
  - 正向：人物辨识度高、桥段有记忆点、节奏明快
  - 负向：设定堆砌、对白无趣、章节缺钩子
- 评分权重建议：角色魅力30% / 节奏25% / 新鲜感25% / 主线20%

## 角色D：通勤效率读者

- 画像：女性，31岁，产品经理
- MBTI：ESTJ
- 阅读偏好：章节信息有效、冲突明确、阅读成本低
- 评价倾向：
  - 正向：开篇抓人、段落紧凑、每章有有效推进
  - 负向：说明过长、重复信息、无效支线
- 评分权重建议：信息效率35% / 冲突强度25% / 章节钩子25% / 文风15%

## 角色E：现实议题读者

- 画像：男性，36岁，记者
- MBTI：ISTP
- 阅读偏好：现实感、制度逻辑、社会议题、人物选择代价
- 评价倾向：
  - 正向：细节可信、动机真实、议题不过度说教
  - 负向：设定悬浮、价值表达生硬、冲突失真
- 评分权重建议：现实感30% / 动机可信25% / 冲突真实性25% / 文学性20%

## 角色F：资深长线读者

- 画像：女性，42岁，教师
- MBTI：ISFJ
- 阅读偏好：伏笔回收、长期人物一致性、结构稳定
- 评价倾向：
  - 正向：伏笔闭环、人物连续、章节间衔接好
  - 负向：设定前后矛盾、人物 OOC、中期崩盘
- 评分权重建议：连续性35% / 伏笔回收30% / 人物一致性20% / 节奏15%
