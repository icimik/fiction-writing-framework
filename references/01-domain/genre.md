# 类型适配与连载策略

## 理论锚点

1. **巴赫金复调小说理论**：打破作者一言堂，让文本呈现多种相互对立、各自逻辑自洽的价值观声音。反派不是工具人，赋予其完整、自洽的价值体系，让冲突上升为理念博弈。

2. **文学接受理论 + 受众使用与满足理论**：作品的意义由作者与读者共同完成。核心受众心理：共情代偿（借主角经历弥补现实缺憾）、爽感宣泄（逆袭破局获得情绪释放）、猎奇探索（追求新奇反转）、价值认同（寻找契合三观）。

3. **好莱坞高概念法则**：用极简反差 + 极致假设打造一句话吸睛亮点。高概念公式 = 颠覆俗套设定 + 极端假设 + 核心冲突。

4. **卡尔维诺晶体叙事法则**：长篇续航的核心心法。主线为晶核，支线、伏笔、单元剧围绕晶核延展，结构紧致、内核统一。

5. **艾柯"开放的作品" + 钩子迭代法则**：留白给读者推理考据。层级化设钩子：章末小钩子、卷末中钩子、全文大钩子。旧悬念落地即抛新悬念。

## 可执行条款（类型适配）

1. 立项时必须指定主类型与辅类型，不得模糊混写。
2. 类型目标、风险与读者期待必须显式写出。
3. 每种类型必须匹配对应工具链与产出模板。
4. 类型反模式必须预先规避并写入检查表。
5. 类型切换或融合时，需记录策略与边界。

## 结构适配规则

各结构的详细实施方法见 `references/01-domain/structure-toolbox.md`。这里只保留题材与结构的适配边界。

1. **慢生活 / 日常系 / 关系推进**
- 默认结构：**丹·哈蒙故事圈**。
- 可搭配：**起承转合** 用于低冲突章节，**Story Grid** 用于场景校验。
- 不推荐默认使用：弗赖塔格金字塔、费希特曲线这类高坠落/高冲突结构。

2. **长篇连载 / 多卷本**
- 默认组合：**三幕结构** 定总骨架，**故事圈** 拆单元，**七点式** 管伏笔回收。
- 需要扩纲时：**雪花写作法** 作为大纲放大器。

3. **成长 / 史诗 / 冒险**
- 优先参考：**英雄之旅**。
- 如果想要更轻量、更适合连续章节：回到故事圈。

4. **悲剧 / 坠落 / 反派弧光**
- 优先参考：**弗赖塔格金字塔**。
- 如果需要角色内部坠落感更强，可借三幕结构中的“失去一切”节点强化。

5. **高冲突 / 悬疑 / 动作 / 副线推进**
- 优先参考：**费希特曲线** 和 **拯救猫咪节拍表**。
- 适合放在章节群中的压力段，不适合覆盖全书日常基调。

6. **多角色群像 / 价值冲突**
- 优先参考：**巴赫金复调** 与 **特鲁比 22 步**。
- 重点不是把所有角色都说得一样响，而是让每个人的价值观都能自洽地撞在一起。

7. **东方留白 / 观察型日常**
- 优先参考：**起承转合**。
- 适合做章节过渡、节气段、留宿段、回家段、尾声段。

## 可执行条款（连载运营）

1. 固定更新节律，不断更拖更。
2. 主线为晶核，支线不跑偏、不冗余注水。
3. 伏笔收一埋一，旧悬念落地即抛新悬念。
4. 角色成长、战力提升循序渐进，不强行开挂。
5. 长篇过半须拟定终局预案，确保终极伏笔平稳落地。

## 脚手架（选题定位）

1. 筛热门赛道：从科幻异能/玄幻奇幻/现实都市/悬疑脑洞/情感言情/历史权谋中，选 1 个主赛道 + 1 个辅元素。
2. 拆解赛道俗套：梳理固化套路，提炼可创新切入点。
3. 反套路 + 复调设计：颠覆 1 个核心俗套，打造高概念亮点，赋予对立面合理价值观。
4. 精准锁定受众：刻画完整读者画像，提炼 3 个核心心理诉求。
5. 敲定选题备案。

## 脚手架（连载节奏）

1. 定更新节律：固定频率 + 时段，储备 2-3 章存稿。
2. 卷纲迭代：每卷完结前，规划下一卷核心主线、灵魂黑夜、高潮与钩子。
3. 伏笔管控：建立台账，标注已收/待收/新埋。
4. 受众互动：筛选合理建议微调细节，不颠覆核心人设与主线。
5. 防崩自查：定期复盘规则、战力、人设。
6. 收尾预案：长篇过半拟定终局。

## 检查项

- [ ] 主辅类型边界清晰。
- [ ] 关键爽点/共情点符合类型预期。
- [ ] 反模式监控已执行。
- [ ] 类型标签与实际内容一致。
- [ ] 平台与类型适配合理。
- [ ] 更新节律稳定，无断更/拖更。
- [ ] 主线始终为晶核，支线不跑偏。
- [ ] 伏笔收埋同步，无大量未填深坑。
- [ ] 人设、战力、世界观无崩坏。
- [ ] 层级钩子齐全。

## 避坑清单

- 不堆砌多题材混搭，坚守 1 主 1 辅。
- 不盲目追热点，优先选擅长且贴合受众的题材。
- 不触碰受众核心避雷点。
- 严禁无节制扩容世界观、新增无关支线。
- 不盲目迎合小众恶意反馈。
- 不随意打破力量体系与世界铁律。
- 不拖延伏笔回收、不堆积无效悬念。
- 不半途更改创作前提。
- 杜绝存稿空窗。

## 失败判定

- 类型目标与写作内容错位。
- 融合类型导致叙事失焦。
- 反模式长期未处理。
