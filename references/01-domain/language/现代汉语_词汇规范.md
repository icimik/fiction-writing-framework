# 现代汉语词汇规范

## 1. 文档定位

本规范用于整理现代汉语词汇的基础体系、核心概念、主要分类、关键辨析方法与写作使用规则，使其能够作为框架内部的标准词汇指南使用。

它的目标不是提供“项目级摘要”，而是提供一份足以支撑项目语言判断的词汇规范。使用者应能通过本文件理解：

1. 现代汉语词汇由哪些单位构成。
2. 词义如何形成、分解和聚合。
3. 同义词、反义词、语体色彩、感情色彩怎样进入实际写作。
4. 熟语、方言词、外来词、古语词、新造词在中文表达中如何使用。

## 2. 词汇和词汇单位

### 2.1 什么是词汇

词汇又称语汇，是一种语言里所有词和固定短语的总和。它既是语言的建筑材料，也是语言中最直接反映社会生活、时代变化、文化心理和认知结构的部分。

从创作角度看，词汇至少承担四项任务：

1. 指认对象。
2. 组织关系。
3. 区分语体和人物。
4. 调整叙述的精度、密度和质感。

### 2.2 词汇单位

现代汉语词汇层最常用的单位有三类：

1. 语素。
2. 词。
3. 固定短语。

#### 2.2.1 语素

语素是语言中最小的音义结合体，是构词单位。

语素与词的区别主要在于：

1. 语素是构词单位，词是造句单位。
2. 语素未必能独立运用，词能够独立运用。
3. 语素可以是词的一部分，词则是比语素高一级的语言单位。

例：

- “山、天、大、好”既可作语素，也可独立成词。
- “阿、子、第、乎乎”等多作语素，不独立成词。

#### 2.2.2 词

词是句中最小的、能够独立运用的语言单位。

判断一个组合是不是词，主要看：

1. 能否独立运用。
2. 中间能否插入其他成分。
3. 语音形式是否稳定。

例：

- “白菜”通常是词，内部不能自由扩展。
- “白布”通常是短语，可扩展为“白色的布”。

#### 2.2.3 固定短语

固定短语是意义整体、形式较固定、可作为现成材料使用的结构。它不等于单个词，但在实际语言中常具有接近词的整体性。

固定短语主要包括：

1. 专称：组织名、活动名、书刊名、影视名等。
2. 熟语：成语、惯用语、歇后语、谚语等。

## 3. 语素系统

### 3.1 按构词能力分类

语素可分为：

1. 自由语素：能独立成词，又能同其他语素组合。
   - 例：人、水、山、大、走。
2. 半自由语素：不能独立成词，但与其他语素组合时位置较灵活。
3. 不自由语素：不能独立成词，组合时位置较固定。
   - 例：第、子、儿等。

### 3.2 按音节形式分类

1. 单音节语素：现代汉语中最常见。
   - 例：天、地、人、说、美。
2. 多音节语素：
   - 双音节语素：多见于联绵词、叠音词、音译词。
   - 三音节及以上语素：多见于音译词。
   - 例：蝴蝶、奶奶、巧克力、奥林匹克。

### 3.3 按意义分类

1. 单义语素：只有一个意义。
2. 多义语素：具有两个或以上义项。

多义语素多见于常用语素，因此写作时尤其要警惕“看似熟悉，实则义项不准”的问题。

### 3.4 按语义属性分类

1. 实义语素：直接负载实际意义。
2. 虚义语素：本身不独立负载实在意义，而主要在组合中体现功能。

### 3.5 按位置分类

1. 定位语素：在合成词中位置固定。
   - 例：“第”通常在前，“子”常在后。
2. 不定位语素：可前可后。
   - 例：“水”可见于“水稻、开水、墨水、油水”等。

## 4. 词的构成

### 4.1 构成要素

1. 词根：表示基本意义的语素。
2. 词缀：附着在词根上，表示附加意义、语法色彩或构词标记的语素。

### 4.2 单纯词

单纯词由一个语素构成，主要类型有：

1. 联绵词：
   - 双声：参差、伶俐、崎岖。
   - 叠韵：窈窕、逍遥、烂漫。
   - 其他：芙蓉、鸳鸯、狼狈。
2. 叠音词：
   - 例：猩猩、潺潺、哗哗。
3. 音译词：
   - 例：咖啡、保龄、迷你。
4. 象声词：
   - 例：叮当、哗啦、扑通。

### 4.3 合成词

合成词由两个或多个语素组合而成，主要有：

#### 4.3.1 复合式

1. 联合型：
   - 例：道路、领导、好歹、缓急。
2. 偏正式：
   - 例：电视、教室、雪白、笔直。
3. 补充型：
   - 例：提高、改正、推广。
4. 动宾型：
   - 例：理发、站岗、起草。
5. 主谓型：
   - 例：地震、胆寒、肉麻。

#### 4.3.2 重叠式

- 例：哥哥、姐姐、偏偏、恰恰。

#### 4.3.3 附加式

1. 词缀 + 词根：
   - 例：老虎、阿姨、第一。
2. 词根 + 词缀：
   - 例：桌子、看头、瓶儿、绿化。

### 4.4 构词使用规范

1. 不要望字生义地拆解固定词。
2. 不要仿造出构词习惯并不支持的伪中文词语。
3. 词缀往往附带语体或感情色彩，不能乱加。

例：

- “专业性、原则性、系统性”成立。
- “阴谋性地微笑”“现实性地发冷”这类搭配往往发硬。

## 5. 词义的性质和构成

### 5.1 词义的性质

词义是词所负载的信息内容。词义的形成依赖人们对客观事物的认识、概括和命名。

现代汉语词义至少有三个基本性质：

1. 概括性：
   - 词义概括共同特征，而不是逐一罗列个体差异。
2. 模糊性：
   - 许多词的边界并非完全精确。
   - 例：“上午 / 中午 / 下午”的边界带有自然模糊性。
3. 民族性：
   - 词义和民族文化、经验、分类方式密切相关。

### 5.2 词义的构成

词义大体可分为概念义和附属义。

#### 5.2.1 概念义

概念义是词的理性内容，主要包含：

1. 对象特征。
2. 适用对象。

例：

- “潮汛”是“一年中定期的大潮”。
- “间谍”是被敌方派遣、收买，从事刺探或颠覆活动的人。

#### 5.2.2 附属义

附属义主要包括：

1. 感情色彩：
   - 褒义、中性、贬义。
2. 语体色彩：
   - 口语、书面语、行业语、方言色彩等。
3. 形象色彩：
   - 视觉、听觉、嗅觉、味觉、动感等形象性。

例：

- “头颅”较书面，“脑袋”较口语。
- “勾当”偏贬义，“业绩”偏褒义。
- “香喷喷、哗啦啦、绿油油”带明显形象色彩。

### 5.3 词义判断的三个层面

写作用词时，不应只看“这个词大概是什么意思”，而应同时问：

1. 它指什么。
2. 它带什么态度。
3. 它是谁会用、在哪种场合用的。

## 6. 词义的分解

### 6.1 义项

义项是词的理性意义的分项说明。一个词有几个稳定意义，就有几个义项。

例：

- “老”可表示年龄大、老年人、经验丰富、陈旧、原来的、经常等。

用词时的规范：

1. 必须先判定义项，再入句。
2. 多义词在具体语境中通常只允许一个义项显现。
3. 若两个义项同时浮现而非刻意为之，往往会导致歧义。

### 6.2 多义词和同音词

#### 6.2.1 多义词

多义词的各义项彼此相关，来源于同一基本意义的派生。

#### 6.2.2 同音词

同音词语音相同而意义无关，常见两类：

1. 同音同形。
2. 同音异形。

同音词的两种作用：

1. 积极作用：构成谐音双关。
2. 消极作用：造成误解和错别字。

### 6.3 义素

义素是构成词义的最小意义单位，也称语义特征。

义素分析的基本步骤：

1. 选取同一语义场中的词。
2. 找出共同义素。
3. 找出区别义素。
4. 用这些特征解释词义差别。

例：

- “鞋 / 靴子 / 袜子”可借“穿在脚上 / 是否有筒 / 是否着地”等义素区分。

## 7. 词义的聚合

### 7.1 语义场

语义场是根据词之间共同语义特征划分出来的意义系统。

特点：

1. 成员彼此相关。
2. 有层次性。
3. 同一词可能属于不同语义场。

例：

- 交通工具场 -> 车辆场 -> 汽车场 -> 卡车场。

### 7.2 同义词

同义词是意义相同或相近的一组词。通常分为：

1. 等义词。
2. 近义词。

#### 7.2.1 等义词

等义词意义几乎完全相同，数量较少，而且往往不会长期并存。

例：

- 斧子 / 斧头。
- 力气 / 气力。

#### 7.2.2 近义词

近义词意义相近，但在色彩、范围、用法、侧重点上存在差异。

例：

- “知道 / 了解”。
- “轻视 / 藐视 / 蔑视 / 鄙视”。
- “边疆 / 边境”。

#### 7.2.3 辨析同义词的主要方法

至少要从三方面辨析：

1. 意义方面：
   - 轻重不同。
   - 范围大小不同。
   - 个体与集体不同。
   - 着重点不同。
2. 色彩方面：
   - 感情色彩不同。
   - 语体色彩不同。
3. 用法方面：
   - 搭配对象不同。
   - 适用对象不同。
   - 词性、句法功能不同。

#### 7.2.4 同义词的作用

1. 使表意更精确。
2. 避免重复。
3. 提供语体和情绪上的微调空间。
4. 满足修辞上的婉曲、讳饰和强化。

### 7.3 反义词

反义词是意义相反或相对的两个词。

主要类型：

1. 绝对反义词：
   - 无中间状态。
   - 例：有 / 无，生 / 死。
2. 相对反义词：
   - 允许中间状态。
   - 例：高 / 矮，先进 / 落后。

反义词的常见作用：

1. 构成对比和映衬。
2. 加强论述和表达力度。
3. 使叙述更简练、鲜明。

## 8. 现代汉语词汇的组成

### 8.1 基本词汇

基本词汇是词汇系统中的主要部分，其特点包括：

1. 全民性。
2. 稳固性。
3. 能产性。

其中构词能力特别强的一部分叫根词。根词是基本词汇的核心，但它不等于词根：

1. 根词是词，是词汇层概念。
2. 词根是语素，是构词层概念。

### 8.2 一般词汇

一般词汇是基本词汇以外的部分，主要包括：

1. 古语词。
2. 方言词。
3. 外来词。
4. 新造词。
5. 专业词语。

#### 8.2.1 古语词

古语词包括：

1. 文言词：所指对象仍在，但现代普通表达已更替。
2. 历史词：所指对象已消失，多见于历史叙述。

用法规范：

1. 文言词可用于庄重、典雅、凝练语体。
2. 历史词只宜在历史语境或特定修辞中使用。
3. 不可为装饰而滥用古语词。

#### 8.2.2 方言词

方言词的吸收应看：

1. 是否具有普通话中没有的意义或形象价值。
2. 是否能增加人物、地域和语境的真实度。
3. 是否会对普通读者造成不必要阻滞。

#### 8.2.3 外来词

外来词进入汉语后，通常要在语音、词法和使用上汉语化。

写作时的规范：

1. 优先使用已稳定规范的形式。
2. 若意译与音译并存，优先看通行度和语体需求。
3. 不用未经吸收稳定的新洋词充当质感。

#### 8.2.4 新造词

新造词是为适应社会发展和表达需要而产生的新词。

规范要求：

1. 合乎汉语构词法。
2. 合乎语义逻辑。
3. 不因求新而生硬。

#### 8.2.5 专业词语

专业词语包括行业语和专门术语。它们可以提升表达的真实度，但也最容易引发表达僵硬和解释腔。

## 9. 熟语

熟语是语言中定型的词组和句子，具有：

1. 结构固定性。
2. 意义整体性。
3. 使用现成性。

### 9.1 成语

成语的主要特点：

1. 长期习用。
2. 结构定型。
3. 意义整体。
4. 多带书面语色彩。

使用规范：

1. 先理解整体义，不可望文生义。
2. 不能随意改字、换词、颠倒语序。
3. 要看感情色彩和适用范围。

例：

- “含辛茹苦”的“茹”是“吃”。
- “尾大不掉”的“掉”是“摆动”。

### 9.2 惯用语

惯用语通常由三音节构成，多为动宾结构，口语色彩较强，意义常带比喻性。

例：

- 开后门。
- 泼冷水。
- 戴高帽。
- 拍马屁。

它与成语的主要差异：

1. 音节数通常不同。
2. 结构稳定性略低于成语。
3. 口语色彩更明显。

### 9.3 歇后语

歇后语由前后两部分组成：

1. 前半部分作引子。
2. 后半部分作说明。

其价值在于形象、风趣、口语性强，但使用时必须注意：

1. 含义明确。
2. 感情色彩健康。
3. 语境允许。

### 9.4 谚语

谚语是长期流传于民间、反映经验或哲理的现成话。

特点：

1. 群众性、口语性强。
2. 概括性强。
3. 常有节奏和记诵便利。
4. 兼具知识性和教育意义。

## 10. 词典和词汇工具的规范地位

在建立项目语言基线时，应重视词典和辞书的校正作用。常见功能包括：

1. 查义项。
2. 查读音。
3. 查词性。
4. 查语体和搭配习惯。
5. 查规范写法。

当项目遇到以下问题时，应优先回辞书校正：

1. 近义词拿不准。
2. 成语疑似望文生义。
3. 书面词和口语词混用。
4. 生僻词是否成立不确定。

## 11. 面向创作的词汇使用规范

### 11.1 先求准确，再求漂亮

词语首先承担指认对象、动作、关系和状态的责任。只有在“说清楚”成立之后，才谈得上质感和风格。

### 11.2 近义词不能凭感觉乱换

高风险场景：

1. 推理说明。
2. 证词和供词。
3. 新闻口径和笔录口径。
4. 多人同场、误认、冒名情境。

### 11.3 词语必须服从人物与载体

不应共用同一套词汇系统的载体包括：

1. 旁白。
2. 人物对白。
3. 聊天记录。
4. 邮件和通知。
5. 通报和笔录。
6. 论坛帖子和私信。

### 11.4 少用抽象兜底词

如：

- 某种意味。
- 某种情绪。
- 某个层面。
- 一种压迫感。

这些词通常不是“高级”，而是具体场面尚未写实。

### 11.5 慎用古语、方言、专业语和外来词

判断标准：

1. 是否真有表达必要。
2. 是否符合人物和语境。
3. 是否会阻断阅读。

## 12. 典型正例 / 误例库

### 12.1 词义与义项

正例：

1. 他把旧信重新翻出来，看了很久。
   - “旧”在这里明确指“以前留下来的”。
2. 她对这个人并不了解，只是听说过名字。
   - “了解”强调认识较深，不与“知道”混用。

误例：

1. 他把老信重新翻出来，看了很久。
   - “老信”若无特定语境，容易发糊；“旧信”更稳。
2. 她对这个人并不十分知道。
   - “知道”一般不这样受程度副词修饰，此处应改为“了解”或重写。

### 12.2 近义词辨析

正例：

1. 我知道他来过，但不了解他来做什么。
   - “知道 / 了解”分别承担浅知与深知。
2. 他显得有些轻视，却还谈不上蔑视。
   - 语义轻重区分清楚。

误例：

1. 我了解他来过，但不知道他来做什么。
   - 前后语义层级倒置，表达不稳。
2. 他只是有点不耐烦，却被写成“鄙视”。
   - 情感强度失真。

### 12.3 语体色彩

正例：

1. 通报写得很正式，他在电话里却只说“这事先别传出去”。
   - 书面口径与口语口径区分清楚。
2. 她在笔录里写“离开现场”，回忆时却说“先走了”。
   - 同一事实在不同载体中词汇切换自然。

误例：

1. 他在群里发消息说：“兹通知诸位，今晚取消聚会。”
   - 若人物并非有意表演，日常聊天里“兹通知诸位”过书面。
2. 公告写成“大家都散了哈，反正今天先这样吧”。
   - 正式文本口径过口语。

### 12.4 感情色彩

正例：

1. 她并不算热情，但做事很稳。
   - 中性判断，不提前贴情绪标签。
2. 他借机替自己开脱，话说得很圆。
   - “开脱”带评价，但有事实支撑。

误例：

1. 她只是沉默，却被旁白直接写成“冷酷”。
   - 评价跨得过大。
2. 他递了一杯水，就被写成“体贴入微”。
   - 感情色彩过满，证据不足。

### 12.5 熟语和固定短语

正例：

1. 他这回算是骑虎难下了。
   - 成语整体义成立，语境匹配。
2. 她总爱给人泼冷水。
   - 惯用语用于口语场景自然。

误例：

1. 他这回算是“骑着老虎很难下来”了。
   - 硬拆成语，破坏定型结构。
2. 她总爱“倒冷水给别人”。
   - 惯用语被字面改写后既不自然，也损失整体义。

### 12.6 抽象兜底词

正例：

1. 他说完那句话，房间里一下安静了。
2. 她把杯子往桌角挪了半寸，谁也没再接话。

误例：

1. 现场开始弥漫出某种复杂情绪。
2. 房间里出现了一种难以言喻的意味。

问题不在“词难”，而在没有把场面写实。

### 12.7 人物与载体一致性

正例：

1. 便签上只写了三个字：先别来。
2. 笔录里写的是：当事人于二十二时十分离开。

误例：

1. 便签上写：本人于今晚决定暂不赴约。
   - 私人便签过度公文化。
2. 笔录里写：他后来就溜了，反正没人注意。
   - 笔录口径过于口语化。

## 13. 快速自检

1. 这个词的义项是否明确。
2. 它的感情色彩和语体色彩是否正确。
3. 这里是否用了近义词却没辨明差别。
4. 是否误用了成语、惯用语或歇后语。
5. 这个词是否属于当前人物、当前场合、当前文本载体。
6. 若把这几个“大词”换成具体动作和对象，句子会不会更好。
