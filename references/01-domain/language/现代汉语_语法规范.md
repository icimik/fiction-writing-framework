# 现代汉语语法规范

## 1. 文档定位

本规范用于整理现代汉语语法的基础体系、主要概念、核心分类、常见结构和写作判断规则，使其能够作为框架内部的标准语法指南使用。

本文件既保留语法学上的基本定义和分类，也补入虚构文学写作中最常用的句法判断、搭配判断和多视角叙事规则。

## 2. 语法概说

### 2.1 什么是语法

语法是语言的结构规则。说写者必须遵循这些规则，听读者也必须借助这些规则理解话语。

“语法”常有两层含义：

1. 语言结构规则本身。
2. 研究这些规则的学科。

### 2.2 语法的特点

现代汉语语法的主要特点有：

1. 抽象性：
   - 有限规则可以生成无限表达。
2. 稳固性：
   - 相较于词汇，语法变化较慢。
3. 民族性：
   - 不同语言在数量表达、定语位置、动宾顺序等方面形式不同。

### 2.3 语法单位

语法研究离不开语法单位。现代汉语常用语法单位由小到大为：

1. 语素。
2. 词。
3. 词组（短语）。
4. 句子。

#### 2.3.1 语素

语素是最小的音义结合体，也是最小的语法单位。

#### 2.3.2 词

词是造句时能够独立运用的最小语言单位。其判断标准常包括：

1. 独立运用。
2. 不能自由扩展。

#### 2.3.3 词组

词组又叫短语，是由两个或两个以上的词组成的语法单位。它是造句单位，但不是最小单位。

#### 2.3.4 句子

句子是语言的基本运用单位。它与词、词组的重要区别在于：

1. 带有语气。
2. 与具体现实语境发生联系。
3. 具有句际停顿边界。

## 3. 词类

### 3.1 词类的分类标准

词类是词的语法分类。现代汉语词类主要依据以下标准判定：

1. 造句能力：
   - 能否充当句法成分。
2. 组合能力：
   - 能与哪些词组合，不能与哪些词组合。
3. 形态变化：
   - 能否重叠，能否带某些标记。

词的类别意义可作辅助标准，但语法特征才是主要标准。

### 3.2 实词与虚词

1. 实词：
   - 能单独充当句法成分。
   - 例：名词、动词、形容词、副词、数词、量词、代词等。
2. 虚词：
   - 不能单独充当主要句法成分。
   - 例：介词、连词、助词、语气词等。

特殊词类：

1. 叹词。
2. 拟声词。

## 4. 实词规范

### 4.1 名词

名词表示人、事物、时间、处所、方位等。

主要语法特征：

1. 一般能受数量词组修饰。
2. 能出现在介词后组成介宾结构。
3. 一般不受“不、很、最”等副词修饰。
4. 常作主语和宾语。

分类：

1. 人物名词。
2. 处所名词。
3. 时间名词。
4. 方位名词。

例：

- 人物名词：学生、老师、山、河流。
- 处所名词：北京、邮局、附近。
- 时间名词：昨天、现在、明天。
- 方位名词：上、下、里、外、前面、后头。

### 4.2 方位词的特别说明

方位词可分为：

1. 单纯方位词：上、下、前、后、里、外等。
2. 合成方位词：上面、后边、里头、以前、之后等。

方位词的常见用法：

1. 跟名词构成方位结构。
2. 跟介词构成介宾结构。
3. 表示时间、方面和界限。

例：

- 树林里。
- 向后转。
- 理论上。
- 四十上下。

### 4.3 动词

动词表示动作、行为、变化、判断、存在、使令、心理活动等。

主要语法特征：

1. 一般能受“不”修饰。
2. 经常作谓语。
3. 大部分能带宾语。
4. 多数可带“着、了、过”。
5. 一部分可重叠。

分类：

1. 一般动词：
   - 行为动词。
   - 心理活动动词。
   - 使令动词。
   - 比似动词。
2. 特殊动词：
   - 助动词。
   - 趋向动词。

例：

- 行为动词：写、走、洗、看。
- 心理活动动词：爱、恨、敬佩。
- 使令动词：让、使。
- 趋向动词：来、去、上来、回去。

### 4.4 助动词

助动词表示可能、必要、意愿等意义。

例：

- 能、可以、会、应该、要、肯、敢。

特点：

1. 多可受“不”修饰。
2. 常作状语修饰动词。
3. 部分可作谓语。

### 4.5 趋向动词

趋向动词表示动作趋向，可分三组：

1. 来、去。
2. 上、下、进、出、过、回、开、起。
3. 上来、上去、下来、回去等复合形式。

除了本义外，趋向动词还有虚化用法：

1. “热起来”中的“起来”表示开始。
2. “坚持下去”中的“下去”表示继续。

### 4.6 形容词

形容词表示性质和状态。

主要语法特征：

1. 一般能受“不”和“很”修饰。
2. 能修饰名词。
3. 一部分能重叠。
4. 能作谓语。

分类：

1. 性质形容词：大、小、红、坚硬、平凡。
2. 状态形容词：通红、雪白、冰凉冰凉、绿油油。

### 4.7 状态词与普通形容词的区别

状态词通常：

1. 不能受“不”修饰。
2. 不能受“很”修饰。
3. 不能像普通形容词那样自由带补语。

例：

- “很干净”成立。
- “很干干净净”通常不成立。

### 4.8 区别词

区别词又叫非谓形容词，常用于名词前作定语。

特点：

1. 不能作谓语。
2. 不能受“不”和“很”修饰。

例：

- 男式、国营、特等、彩色、主要。

### 4.9 数词

数词表示数目和次序。

重点规则：

1. 常与量词组合。
2. “第、初”可表示序数。
3. 概数可用“多、来、上下、左右”等表示。
4. 倍数和分数有固定格式。
5. “两”和“二”有分工。
6. “一”有活用现象。

例：

- 三本书。
- 第一章。
- 两百块，二十二次。
- 一学就会。

### 4.10 量词

量词表示计算单位。

主要语法特征：

1. 能与数词或指示代词组合。
2. 一部分可重叠。

分类：

1. 物量词：
   - 个、条、本、张、双、堆、些、点儿。
2. 动量词：
   - 次、回、趟、遍、下、番。

使用规范：

1. 名词和动词通常要求特定量词。
2. 同一对象换量词，意义侧重点会变。

例：

- 一场雨 / 一阵雨。
- 解释一番 / 解释一下 / 解释一遍。

### 4.11 副词

副词最突出的语法特征是作状语。

常见类别：

1. 程度副词：很、非常、最。
2. 情状副词：亲自、赶紧、悄悄。
3. 频率副词：再、又、一再。
4. 时间副词：已经、正在、刚刚、终于。
5. 范围副词：都、只、统统。
6. 否定副词：不、没、别、未。
7. 语气副词：难道、居然、简直、幸亏。

重点规范：

1. 副词位置常影响句义。
2. “不”和“没”不能任意互换。
3. 副词与可作状语的形容词要区分。

### 4.12 代词

代词代替实词或词组，主要分为：

1. 人称代词。
2. 指示代词。
3. 疑问代词。

人称代词中的细微规则也很重要：

1. “咱们”一般包括听话人，“我们”未必包括。
2. “您”是敬称。
3. “人家”与“别人”不总能互换。

代词还有活用现象：

1. 不定指。
2. 任指。
3. 虚指。

### 4.13 叹词与拟声词

虽然不属于常规实词系统，但它们在现代汉语里具有独立功能：

1. 叹词：唉、哦、哎呀、哼。
2. 拟声词：叮当、哗啦、嗞、当啷。

特点：

1. 可单独成句。
2. 常不与其他成分形成稳定句法关系。

## 5. 虚词规范

### 5.1 虚词的基本特征

虚词主要表示语法关系和语法意义，不独立充当主要句法成分。现代汉语高度依赖虚词来表达结构关系、动态意义和语气色彩。

### 5.2 介词

介词常表示：

1. 时间、处所。
2. 方式、依据。
3. 原因、目的。
4. 对象、范围。
5. 被动、比较。

介宾结构通常作状语，也可作定语或补语，但一般不作谓语。

常见介词：

- 从、在、向、按、根据、为、由于、对、把、被、比。

#### 5.2.1 介词与动词的区别

许多介词由动词演变而来，因此须区别兼类情况。

判断方法：

1. 能否肯定否定相叠。
2. 前后是否还有别的动词。
3. 能否带动态助词“了”。

### 5.3 连词

连词用于连接词、词组或分句，主要表示：

1. 并列。
2. 选择。
3. 递进。
4. 因果。
5. 转折。
6. 假设。
7. 条件。

例：

- 和、并、或者、因为……所以、虽然……但是、只要……就。

### 5.4 助词

助词主要有三类：

1. 结构助词：
   - 的、地、得。
2. 动态助词：
   - 了、着、过。
3. 其他语法助词：
   - 似的、所等。

规范重点：

1. “的 / 地 / 得”分工要清。
2. 动态助词的时间与状态意义要清。

### 5.5 语气词

语气词位于句末或句中，表达语气、停顿和口吻。

例：

- 吗、吧、呢、啊、罢了。

使用规则：

1. 不同人物的语气词习惯不同。
2. 书面叙述不宜滥用。
3. 对白中的语气词应服从人物口气。

## 6. 词类误用

常见错误包括：

1. 名词误作形容词。
2. 名词误作动词。
3. 形容词误作动词。
4. 名词误作副词。

例：

- “兴致地观赏”不稳，应改为“兴致勃勃地观赏”或“饶有兴致地观赏”。
- “优越彩色照片”不稳，应改为“优于彩色照片”。

## 7. 词组规范

### 7.1 偏正词组

前一部分修饰、限制、说明后一部分。

可分为：

1. 名词性偏正词组。
2. 动词、形容词、状态词性的偏正词组。

例：

- 白衬衣。
- 刻苦学习。
- 非常努力。

### 7.2 述宾词组

前一部分是述语，后一部分是宾语，二者之间为支配关系。

例：

- 吃米饭。
- 研究哲学。
- 觉得不舒服。

### 7.3 述补词组

前一部分是述语，后一部分是补语，二者之间为补充关系。

例：

- 看懂。
- 走进来。
- 洗得干净。

### 7.4 主谓词组

由主语和谓语构成，二者之间是陈述关系。

例：

- 他去。
- 环境优美。
- 张三是学生。

### 7.5 联合词组

各组成成分平等并列。

可表示：

1. 并列。
2. 选择。
3. 递进。

例：

- 爸爸和妈妈。
- 今天或明天。
- 多而好。

### 7.6 连动词组

几个动词性成分连用，动作多由同一主体发出。

例：

- 下课打篮球。
- 去上课。
- 看电影去。

### 7.7 兼语词组

前一部分宾语同时又是后一部分的施事或主体。

例：

- 请你提意见。
- 派小李去。
- 称赞她聪明。

### 7.8 简单词组与复杂词组

1. 简单词组：由单词组成。
2. 复杂词组：内部还包含词组。

复杂词组应以层次分析法判断结构。

## 8. 句子与句法成立

### 8.1 什么叫成立的句子

一个句子至少应能还原出基本主干。即使有省略、倒装、独词句、无主句，也必须让中文读者能自然补回关系。

不成立的常见情况：

1. 只有词，没有句法关系。
2. 只有修饰，没有中心。
3. 动词没有支配对象。
4. 主语不可能承担该动作。

### 8.2 短语不能冒充句子

高风险写法：

1. 偏正短语当成完整叙述。
2. 名词块当成判断句。
3. 修饰链条当成事件推进。

### 8.3 省略的边界

可以省略：

1. 上下文已稳定建立的主语或宾语。
2. 对话中自然可回补的成分。
3. 合法的无主句和独词句。

不能省略：

1. 导致指向混乱的主语。
2. 让动作失去对象的宾语。
3. 误认和多 POV 段中的关键关系。

### 8.4 语序和虚词

现代汉语高度依赖语序和虚词。以下项目应高频校验：

1. 的 / 地 / 得。
2. 了 / 着 / 过。
3. 把 / 被。
4. 在 / 对 / 给 / 从 / 跟。
5. 即使 / 尽管 / 但是 / 却 / 才 / 就。

## 9. 句法成分

句法成分是词、词组进入句子后所承担的语法角色。现代汉语中最常用的句法成分包括：

1. 主语。
2. 谓语。
3. 宾语。
4. 定语。
5. 状语。
6. 补语。
7. 中心语。
8. 独立语。

### 9.1 主语

主语是被陈述的对象，常由名词性成分充任，也可由谓词性成分或主谓短语充任。

例：

- “他来了”中的“他”。
- “学习很重要”中的“学习”。

### 9.2 谓语

谓语是对主语加以陈述的成分，常由动词、形容词、主谓短语或名词性成分充任。

例：

- “他来了”中的“来了”。
- “天很冷”中的“很冷”。
- “她是医生”中的“是医生”。

### 9.3 宾语

宾语是述语支配、涉及的对象，常位于动词之后。

例：

- “看书”中的“书”。
- “觉得不舒服”中的“不舒服”。
- “知道他已经走了”中的“他已经走了”。

### 9.4 定语

定语是名词性中心语前的修饰、限制成分。

例：

- 红衣服。
- 昨天的消息。
- 非常重要的决定。

### 9.5 状语

状语是动词、形容词、状态词前的修饰、限制成分。

例：

- 认真学习。
- 非常清楚。
- 悄悄地走进来。

### 9.6 补语

补语位于述语之后，补充说明结果、程度、趋向、可能、状态等。

例：

- 写完。
- 看得清楚。
- 跑过去。

### 9.7 中心语

中心语是偏正词组中被修饰、被限制的核心成分。

例：

- “白衬衣”中的“衬衣”。
- “认真学习”中的“学习”。

### 9.8 独立语

独立语在句中不与其他成分发生直接结构关系，常用来表示称呼、插入、感叹、提示等。

例：

- 老实说，我不赞成。
- 喂，你先等等。
- 总之，这件事得重查。

## 10. 单句、复句与关系组织

### 10.1 单句

单句是在句子内部只包含一个主谓框架的句子。它可以简单，也可以复杂；复杂不等于复句。

例：

- 他今天没来。
- 我们在雨里慢慢地走回去。

### 10.2 复句

复句由两个或两个以上在意义上相关、结构上相对独立的分句组成。

常见关系包括：

1. 并列。
2. 承接。
3. 递进。
4. 选择。
5. 转折。
6. 因果。
7. 条件。
8. 假设。
9. 让步。
10. 目的。

### 10.3 常见复句关系及标记

1. 并列：
   - 既……又……
   - 一边……一边……
2. 承接：
   - 然后、接着、于是
3. 递进：
   - 不但……而且……
4. 选择：
   - 或者……或者……
   - 不是……就是……
5. 转折：
   - 虽然……但是……
   - 可是、却
6. 因果：
   - 因为……所以……
   - 因此
7. 条件：
   - 只要……就……
   - 只有……才……
8. 假设：
   - 如果……就……
   - 假如……那么……
9. 让步：
   - 即使……也……
10. 目的：
   - 为了……
   - 以便……

### 10.4 复句写作规范

1. 关联词要配套。
2. 关系一旦确立，不要中途偷换。
3. 分句之间要有清晰的逻辑顺序。
4. 多层复句应先稳主关系，再加次关系。

高风险错误：

1. “尽管……也……”误作让步标记。
2. 让步、转折、因果混写。
3. 关联词过多，导致结构臃肿。

## 11. 多义短语

### 11.1 什么是多义短语

多义短语是意义有两种或几种解释的短语。主要成因包括：

1. 词语本身多义。
2. 词和短语界限模糊。
3. 结构层次不同。
4. 结构关系不同。
5. 语义关系不清。

例：

- “买红花”中的“红花”可作药材词，也可作偏正短语。

### 11.2 多义短语的分化方法

1. 换用词语。
2. 借助语境。
3. 变换语序。
4. 增删成分。
5. 口语中利用停顿。

## 12. 面向创作的句法规则

### 12.1 先查主干，再谈风格

判断一句话之前，先看：

1. 谁在做事。
2. 做了什么。
3. 对谁或对什么。
4. 结果怎样。

### 12.2 高风险句法问题

1. 主语错位。
2. 动宾失配。
3. 修饰语悬空。
4. 关联词错配。
5. 指代不明。
6. 判断句发硬。
7. 名词化过重。

### 12.3 多 POV 和多人同场

1. 同章只跟一个 POV 时，代词系统必须稳定。
2. 多人同场时，能点名就少用“他 / 她 / 对方”。
3. 误认、冒名、双身份场景要保证回读可还原。

### 12.4 推理叙事专项

1. 解释段不能写成编号式汇报。
2. 证据链要靠句法顺序推进。
3. 供词段要保留人的口气和停顿。

## 13. 典型正例 / 误例库

### 13.1 主干成立

正例：

1. 群消息很快刷了上去。
   - 主语“群消息”能够承担“刷上去”这一变化。
2. 门外有人敲了两下，又停住了。
   - 动作承担者和动作顺序清楚。

误例：

1. 群里很快开始往上翻。
   - 主谓关系不成立，“群里”不是会“往上翻”的对象。
2. 门外出现了一种敲门。
   - 动词和宾语关系错误。

### 13.2 动宾搭配

正例：

1. 他翻完记录，又对照了时间表。
2. 她解释了一遍经过。

误例：

1. 他翻完了一个怀疑。
   - “翻完”不能支配“怀疑”。
2. 她对照了一个紧张。
   - 宾语不是可被“对照”的对象。

### 13.3 修饰语落点

正例：

1. 他把湿外套搭在椅背上。
   - “湿”明确修饰“外套”。
2. 她很慢地把那句话说完。
   - 状语落点清楚。

误例：

1. 他把椅背上的湿搭在外套上。
   - 词类和结构关系都乱。
2. 她把很慢说完了那句话。
   - 状语位置不合习惯。

### 13.4 省略边界

正例：

1. “见到了吗？”“见到了。”
   - 对话中主语宾语可自然补回。
2. 她推门进去，没开灯。
   - 后句主语可由上文稳定承接。

误例：

1. 推门进去，没开灯，他盯了她一眼。
   - 前半句主语可能是“她”也可能是“他”，省略导致指代不稳。
2. 桌上放着，后来就没了。
   - 核心宾语缺失，读者无法补回。

### 13.5 关联词配套

正例：

1. 虽然他解释了很久，但是没人信。
2. 即使今天查不完，也得先把目录做出来。

误例：

1. 尽管天塌下来，我也能顶得住。
   - 现代汉语里此处通常应用“即使……也……”。
2. 因为他不在，所以但是会议还是开了。
   - 关系词混搭。

### 13.6 代词与多人物同场

正例：

1. 陈凯文看了林江明一眼，林江明却没有抬头。
   - 连续点名，动作归属清楚。
2. 她把手机递给余瑶时，余瑶没接。
   - 指代链稳定。

误例：

1. 他看了他一眼，他却没有抬头。
   - 三个“他”导致人物关系无法追踪。
2. 她递给她的时候，她没接。
   - 动作执行者和接收者都发糊。

### 13.7 复句关系

正例：

1. 因为监控坏了，所以他们只能回头查门禁。
2. 如果他昨晚真的来过，门口不可能没有记录。

误例：

1. 因为监控坏了，但是他们只能回头查门禁。
   - 因果和转折混用。
2. 如果他昨晚真的来过，所以门口不可能没有记录。
   - 假设与因果误配。

### 13.8 推理说明段

正例：

1. 林江明把打印好的门禁记录推过去，先指了二十二时零七分那一行。
2. 她话说到一半停住，陈凯文才接上后面的判断。

误例：

1. 第一，门禁有问题。第二，监控有问题。第三，所有人都有问题。
   - 讲义腔过重，句法虽完整，叙事却塌成条目。
2. 真相就是一个已经成立的完整闭环。
   - 判断句抽象化、名词化过重。

## 14. 快速自检

1. 这句能否还原主干。
2. 主语、动作、对象、结果是否对得上。
3. 这句是留白还是没写完。
4. 代词会不会让人物和动作错位。
5. 去掉修饰后，这句还成不成立。
