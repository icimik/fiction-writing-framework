# 中文生成约束

## 1. 文档定位

本文档是生成中文正文时的操作手册。

它不是语言学参考，不是教材整理，不是风格指南。它只做一件事：**在生成环节防止 LLM 输出翻译腔中文。**

与其他文档的关系：

- 本文档 → 框架级生成约束，所有项目生效，生成正文前必读。
- `STYLEGUIDE.md` → 项目级风格约束，定制题材和角色。
- `SOUL.md` → 角色级声线约束。
- `现代汉语_词汇规范.md` / `现代汉语_语法规范.md` / `现代汉语_修辞规范.md` → 语言学参考，需要追溯规则依据时才查。

上游追溯：

- 本文档的规则来自框架验证项目的实际翻译腔问题积累，不来自教材。

## 2. LLM 翻译腔的成因

LLM 生成中文时产生翻译腔，根源不是"不懂中文语法"，而是**默认以英语逻辑组织句子，再用中文词汇填充。**

具体机制：

1. 内部推理以英语句法为骨架（SVO 长句、名词化、从句嵌套），输出时逐词替换为中文。
2. 英语靠连接词（however / therefore / because）显性标记逻辑关系，中文靠语序和意合。LLM 把英语连接词习惯带入中文。
3. 英语高频使用被动语态和名词短语承载信息（nominalization），LLM 在中文中复制这种倾向。
4. 英语学术和非虚构写作习惯"先结论再展开"，LLM 把这种模式带入小说叙事，导致概念先行、解释驱动。
5. 英语定语从句可以灵活后置，LLM 生成中文时把大量信息硬塞进名词前面，造成前置修饰堆叠。

这些问题的关键特征是：**每一句单独看都"说得通"，但读起来不像中文母语者写的。** 正是因为"说得通"，所以靠事后精修很难根治——必须在生成时就改变组句方式。

## 3. 高频翻译腔模式与替换策略

以下是 LLM 生成中文时最高频的翻译腔模式。每条给出识别特征、反面示例和正面替换。**生成时必须主动规避。**

### 模式 1：压缩名词式主语

识别：主语是"XX 的 XX 导致的 XX"型多层名词短语。

- 反面：他的长期失业导致的经济压力使得家庭关系日趋紧张。
- 正面：他失业快两年了，家里的钱越来越紧，跟老婆说话也越来越少。

规则：中文的信息承载单元是动词，不是名词短语。遇到多层"的"字短语作主语，拆回动词句。

### 模式 2：抽象概念作主语 + 使役动词

识别：主语是"不确定性""可能性""现实""命运""贫困"等抽象名词，谓语是"使""让""令""导致"。

- 反面：这种不确定性让他感到了深深的焦虑。
- 正面：他不知道下个月房租怎么办，晚上翻来覆去睡不着。

规则："让他感到"是英语 "made him feel" 的直译。遇到抽象主语 + "让/使/令"，换回具体的人做具体的事。

### 模式 3：连接词过密

识别：一个句群内同时出现"尽管""但""由于""因此""然而""并且"等连接词超过两个。

- 反面：尽管他知道这样做不对，但由于经济压力的迫使，因此他还是选择了接受。
- 正面：他知道不对。但钱的事逼到眼前，还是点了头。

规则：中文靠语序表达逻辑关系，一个句群内保留一个关键连接词就够了。"尽管 A，但由于 B，因此 C"是英语复合句式的直接移植。

### 模式 4：被动语态

识别：高频出现"被……所……""被……着""受到……的影响"。

- 反面：他被这种无力感所笼罩，被生活的重担所压迫。
- 正面：他觉得什么都做不了，每天一睁眼就是还不完的账。

规则：中文被动句的自然使用频率远低于英语。大多数情况下换回主动句或无主句更地道。中文被动句主要用于不愉快、不期望的事，且多用简明"被"字句，不叠加"所"。

### 模式 5：前置修饰堆叠

识别：名词前有三层以上修饰语。

- 反面：在那个阴暗潮湿的、充满了各种霉味和旧报纸气味的、几乎看不到阳光的地下室里。
- 正面：地下室见不到阳光，到处是霉味，墙角堆着发黄的旧报纸。

规则：中文定语宜短。超过两层修饰立即拆成分句或补语结构。英语定语从句可后置展开，中文没有这个机制，硬塞到名词前面只会让句子发闷。

### 模式 6：概念先行 + 解释展开

识别：段落以一个抽象判断开头，后面跟"比如说""具体来讲""这体现在"。

- 反面：贫困不仅仅是经济上的匮乏，更是一种系统性的压迫。丹尼尔深刻地体会到了这一点。
- 正面：丹尼尔在药房柜台前站了五分钟，最后把止痛药放了回去。十七块八，够凯勒布两天的午饭钱。

规则：小说先给场面、动作、物件，结论由读者自己得出。"不仅仅是……更是……"是论文句式，不是叙事句式。

### 模式 7：情绪/概念总结句收尾

识别：段落或章节末尾出现"他感到……""这一刻他意识到……""就这样，……在……中度过了"。

- 反面：这一天就这样在疲惫和焦虑中度过了，丹尼尔感到前所未有的绝望。
- 正面：丹尼尔关了灯。闹钟显示凌晨一点，明天六点还得起来送孩子。

规则：段落不用情绪标签收尾。用物件、时间、未完成的动作或一句没说完的话收尾。

### 模式 8：对话中的书面腔

识别：日常场景中人物说出书面语或完整议论句。

- 反面："我认为我们需要重新评估一下当前的财务状况。"
- 正面："钱的事得说说了。"

规则：对白服从角色身份、场合和当下状态。疲惫的人说短句，着急的人说半截话，底层角色不会在厨房里说出政策分析语句。

### 模式 9：情绪标签代替展示

识别：出现"一种复杂的情绪""矛盾的心情""五味杂陈""说不清的感觉"。

- 反面：他心中涌起一股复杂的情绪，既有愤怒，也有无奈，还有一丝不易察觉的愧疚。
- 正面：他把钥匙往桌上一扔，在门口站了一会儿，才把鞋脱了。

规则：不给情绪贴标签。用动作、停顿、物件和生理反应让读者自己感受到情绪。罗列式情绪标注（"既有 A，也有 B，还有 C"）是英语写作教程中 "show, don't tell" 原则的反面——偏偏 LLM 在中文中经常犯。

### 模式 10：段落结构整齐重复

识别：连续三段以上使用相同的内部节奏（如"背景 → 行动 → 感受 → 总结"反复循环）。

- 反面：每段都是"他走进房间。做了某事。感到某种情绪。"的三段式。
- 正面：长短段交替。有时一句话就是一段。有时连续动作推进不给停顿。偶尔一段只有对白。

规则：朗读连续五段。如果能预测到每段的结构走向，说明段落节奏死了，必须打散。

### 模式 11：句子开头雷同

识别：连续多句以同一种方式起头——"他""她""这""那""然而"反复出现在句首。

- 反面：他站起来。他走到窗前。他看了看外面。他叹了口气。
- 正面：他站起来，走到窗前。外面下着雨，路灯把水洼照成一片一片的橙色。

规则：连续三句以上同一主语起头，合并或换主语。中文叙事的自然节奏是：主语出场后可省略，直到需要切换关注对象。

### 模式 12：副词堆叠在动词前

识别：动词前有三个以上副词/状语。

- 反面：他几乎不可能再继续假装淡定地微笑着面对这一切了。
- 正面：他绷不住了，嘴角的笑意一下子收了回去。

规则：中文的动词不适合被一长串前置状语压住。动作的方式、程度、可能性，优先用补语和后续分句表达。

## 4. 中文叙事的正面特征

以下不是"规则"，而是"锚定"——好的中文叙事读起来具有这些特征。生成时可以用这些特征做自检。

1. **动词驱动**：句子的核心力量来自动词，不来自名词短语或形容词堆叠。
2. **短中句为主**：常用句长 10-25 字，长句偶尔用于铺排，但不是常态。
3. **语序即逻辑**：因果关系通过先写原因再写结果来表达，不必标"因为……所以……"。
4. **留白多于铺满**：不把每个转折、每层因果都显性写出来。信任读者的补全能力。
5. **人和物先于概念**：先出人、物、空间，再出（或不出）抽象判断。
6. **节奏靠长短交替**：短句给冲击，长句给铺展，断句给停顿——不是匀速流淌。
7. **口语和书面的自然混用**：叙述可以偏书面而不失自然，对白可以碎而不失信息。两者之间有语体落差是对的。
8. **尾句克制**：好的段落结尾留一个画面或动作，不替读者做情绪总结。

## 5. 生成时三阶段检查

### 5.1 生成前（每段）

1. 这一段的叙事任务是什么？（回答"发生什么事"，不是"表达什么概念"）
2. 这一段由谁感知、谁行动？
3. 入段方式是否和前一段雷同？如果是，必须换一种。

### 5.2 生成中（每句）

1. 当前句子的主语是不是抽象名词？→ 如果是，换回人或物。
2. 当前句子是不是在解释而不是在叙述？→ 如果是，先回到动作或场面。
3. 当前句子的连接词是否超过两个？→ 如果是，拆句。
4. 当前句子的动词前面是否堆了三个以上修饰语？→ 如果是，拆到动词后面或另起分句。
5. 当前句子是不是可以删掉一半仍然成立？→ 如果是，删。

### 5.3 生成后（每段、每章）

每段回查：

1. 朗读这一段。像中文小说，还是像翻译文学？
2. 把段中所有"使得""导致""意味着""表明""令人"标出来，尝试全部消除。
3. 段尾是不是情绪或概念总结句？→ 如果是，换成物件、时间或动作。

每章回查：

1. 全章是否存在三段以上的段落结构雷同？
2. 全章的句子开头是否存在连续雷同？
3. 全章的对白是否区分了角色身份和当下状态？
4. 全章读完后的直觉：这是一个中文故事，还是一篇翻译稿？

## 6. 常见"看似高级实则翻译腔"的句式清单

以下句式在英语学术写作或非虚构写作中合理，但在中文小说叙事中几乎总是翻译腔。遇到时应先考虑是否能消除。

1. "这使得……成为可能" → 直接写谁做了什么事。
2. "在某种意义上来说" → 删掉，直接说。
3. "值得注意的是" → 删掉，直接写值得注意的内容。
4. "与此同时" → 用时间顺序或场景切换替代。
5. "从某种角度来看" → 删掉，角度由语境自然体现。
6. "正如前文所述" → 删掉，小说不引用自己。
7. "不可否认的是" → 删掉，直接陈述。
8. "事实上" → 大多数时候可删掉。
9. "在……的背景下" → 先写事件，再写背景（如果需要的话）。
10. "这一切都指向了一个事实" → 删掉，让事实自己出场。
11. "他/她开始意识到" → 写出让他/她意识到的那个具体瞬间。
12. "某种难以言喻的感觉" → 如果真的难以言喻，用动作和画面暗示。如果只是偷懒，那就把感觉写出来。

## 7. 与项目级文档的配合

### 7.1 执行优先级

1. 本文档的模式识别和替换策略 → 所有项目生效。
2. 项目 `STYLEGUIDE.md` 的题材和角色定制 → 项目内生效。
3. 角色 `SOUL.md` 的声线定制 → 角色出场时生效。
4. 三份语言规格 → 追溯规则依据时使用。

### 7.2 配合方式

1. 生成正文前，先读本文档（框架级约束），再读项目 `STYLEGUIDE.md`（项目级定制），再读当前 POV 角色的 `SOUL.md`。
2. 项目 `STYLEGUIDE.md` 中关于中文表达的规则，应是本文档的题材化延伸，而不是重新发明一套规则。
3. 若项目发现了本文档未覆盖的新翻译腔模式，应在项目复盘时回写到本文档。

## 8. 快速自检

生成任何中文正文后，至少过以下 8 问：

1. 这段里有没有抽象名词当主语的句子？→ 全换回人或物。
2. 有没有"让/使/令 + 感到"的句式？→ 全换回具体场面。
3. 有没有连续两个以上连接词的句子？→ 拆句。
4. 有没有段尾总结句？→ 换成物件或动作。
5. 有没有连续三段结构雷同？→ 打散。
6. 有没有书面腔对白？→ 按角色和场合重写。
7. 有没有第 6 节清单里的句式？→ 逐条检查消除。
8. 朗读全段。听起来像中文小说还是翻译文学？→ 如果后者，整段重写。

## 9. 精修与重塑方法手册

本节是阶段 7（整书审读与中文表达精修）和阶段 7b（中文重塑）的操作方法详解。

### 9.1 为什么「在原文上改」容易失效

根因：用同一个 LLM 精修它自己生成的翻译腔，往往只是把"翻译腔 A"改成"翻译腔 B"。

机制：
- LLM 在精修模式下会被原文的句法骨架锡定（anchoring），只能做表面词汇替换，无法跳出原文的英语逻辑结构。
- "修改这段话"这个指令内含了"保留原文结构"的隐含假设。而正是原文结构才是问题所在。
- 反复在同一段上执行多轮标准精修不会收敛，只会浮动。

判断标准：
- 一段文本经过一轮「给 LLM 原文让它改」后朗读仍不自然，必须立即切换到重述法，不得再试一轮相同操作。

### 9.2 阶段 7 默认方法

阶段 7 的标准动作已将以下方法设为默认操作，不再是「失效后的升级」：

- **重述法**是默认精修方式（步骤 3）。
- **分层法**用于高风险章节（步骤 4）。
- **锚文本法**在有项目语言参考时每批附带使用。
- **删减法**在整书回读时执行（步骤 5）。

详见 `references/02-process/stages.md` 阶段 7 标准动作。

### 9.3 阶段 7b 独立重建流程

当阶段 7 完成后仍有超过 30% 章节存在系统性翻译腔，且用户明确授权，进入阶段 7b「中文重塑」。

核心区别：阶段 7 是在现有文本上精修；阶段 7b 是从叙事任务重建，原文只用于提取叙事任务和事后比对，不作为生成输入。

标准动作：提取叙事任务清单 → 逐章重建 → 对白单独一轮 → 删减轮 → 整书回读 → 联动更新。

详见 `references/02-process/stages.md` 阶段 7b。

### 9.4 四种方法详解

以下四种方法按优先级排序。前三种互斥（对同一段选一种），删减法可叠加。

#### 方法 1：重述法（优先级最高）

核心操作：不给 LLM 原文，只给叙事任务，让它重新写。

步骤：
1. 用一两句话写清当前段落的叙事任务：谁在哪里做什么，发生了什么，结果是什么。
2. 用具体事件而非抽象概括描述任务。
   - 正确："他在药房柜台前站了五分钟，最后把止痛药放回去。"
   - 错误："展现贫困对日常生活的影响。"
3. 让 LLM 从叙事任务出发写这一段，不提供原文。
4. 写完后检查：新段落是否保留了原段必须携带的信息点（人名、时间、物件、因果关系）。

为什么有效：拔掉原文，LLM 的句法锡定就消失了，它会从中文的叙事习惯出发组织句子。

#### 方法 2：锚文本法

核心操作：给 LLM 一段达标的中文小说段落作为语感样本，让它按这个语感重写目标段落。

步骤：
1. 找一段你认为达标的中文小说段落（自己写的或别人的）。
2. 放在 prompt 开头，说"请按这个语感重写下面的段落"。
3. 再给出要精修的段落。

材料来源：
- 若项目已有 `09-assets/项目写作语言参考_*.md`，优先从中抽取。
- 若未建立，从本项目已经写得好的章节中抽取。
- 若整书都不达标，从同题材的中文小说中抽取。

为什么有效：LLM 对具体文本的模仿力远强于对抽象规则的执行力。200 字的锚文本比 2000 行规则文档更能校准语感。

#### 方法 3：分层法

核心操作：不一次精修全部，而是分三轮，每轮只处理一种问题。

步骤：
1. 第一轮：只对白
   - 把所有对白按角色身份、体力状态和当下场景重写。
   - 不碑叙述部分。
2. 第二轮：只改段首和段尾
   - 段首是翻译腔最容易出现的位置（过多阿抽象主语、概念先行）。
   - 段尾是情绪标签和总结句的高发区。
3. 第三轮：只删
   - 不改写，只删除冗余的连接词、情绪标签和总结句。

为什么有效：每轮注意力集中在一种问题上，输出质量比"通读改全部"高得多。

#### 方法 4：删减法（可与其他方法叠加）

核心操作：对段落只做减法，不做改写。

步骤：
1. 删所有可删连接词（"然而""因此""与此同时""尽管如此"），看句意是否仍然成立。
2. 删所有"使得""导致""意味着""让他感到""令人"，强制补具体动作。
3. 删段尾总结句。
4. 删所有"某种""无法言喋""难以形容"等偷懒词。

为什么有效：删不会引入新的翻译腔。改会。

### 9.5 操作约束

1. 一段文本经过一轮标准精修后仍不自然，不得再试一轮相同操作。必须升级。
2. 不得连续用标准精修处理同一段超过两次。
3. 优先级：重述法 > 锚文本法 > 分层法。删减法可叠加。
4. 重述法写完后必须核对原段的信息点，确保人名、时间、物件、因果关系未丢失。
5. 锚文本的语感应与本项目的题材和气质匹配，不允许用轻小说锚文本改写现实向小说。
6. 修复方法的使用必须记录在工作日志和变更记录中，包括：哪些章节、使用了哪种修复方法、是否成功。
