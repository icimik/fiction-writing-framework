# 叙事

## 理论锚点

1. **什克洛夫斯基"陌生化"理论**：文学语言的核心是将熟悉事物陌生化，延长读者感知时间。不直白写"痛苦/寒冷/愤怒"，改用通感、具象细节描写。

2. **契诃夫的枪 + 自由间接引语**：文中所有意象、道具、细节必服务剧情/情绪/伏笔，无用内容果断删除。摒弃直白心理描写，将环境描写与角色情绪融合——"一切景语皆情语"。

3. **Story Grid 场景诫命**：每个场景都要有触发事件、递进复杂化、危机、高潮、结局。场景层面的判断标准不是“写得多”，而是“有没有真的发生变化”。

4. **起承转合的留白能力**：适合低冲突、观察型、日常系段落。尤其在“转”处引入意外观察或视角偏移，在“合”处留下余味，而不是硬性收束。

## 可执行条款

1. 每章固定主视角；视角切换必须有明确边界。
2. 叙事距离需标注策略（近/中/远），并保持一致性。
3. 信息释放遵循"必要即给"，不得超前剧透核心谜底。
4. 时间结构必须显式管理（线性/插叙/并行），避免时间混乱。
5. 叙述声音需稳定：语气、词汇层级、叙述立场不频繁跳变。

## 脚手架

1. 定固定视角：商业文选第三人称限知（主角视角），悬疑/情感可选第一人称。
2. 定文风基调：轻小说/网文走短句对话流，纯文学走长短句结合。
3. 对话驱动：对话含人设、信息、情绪博弈，占比 ≥ 50%。
4. 落实陌生化 + 契诃夫的枪：高潮用白描短句，抒情用具象修辞，删除无效细节。
5. 信息克制：不提前剧透，用留白、伏笔保留悬念。
6. 场景校验优先：一场戏先问自己有没有触发、升级、选择和结果，没有就重写。

## 产出要求

- `视角信息表.md`
- `叙事距离标注.md`
- `时间结构表.md`

## 检查项

- [ ] 读者能明确当前视角主体。
- [ ] 关键信息没有越权泄露。
- [ ] 时间线可追踪，无前后矛盾。
- [ ] 叙述声音统一且可识别。
- [ ] 信息密度与节奏匹配（不过载/不过空）。
- [ ] 无废笔，细节均服务剧情/情绪/伏笔。
- [ ] 运用陌生化技巧，无套路化直白描写。

## 避坑清单

- 不用复杂长句，适配碎片化阅读。
- 不堆砌生僻辞藻，降低阅读门槛。
- 不强行煽情，用细节传递情绪。
- 不提前泄露伏笔，保持剧情悬念。

## 失败判定

- 视角乱跳导致理解中断。
- 时间线错位影响因果关系。
- 叙述口吻断裂破坏沉浸感。
