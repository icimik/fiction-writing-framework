# 参考文本与资料来源

## 参考文本使用规范

### 可执行条款

1. 参考文本仅用于拆解结构与技法，不得直接拼接改写。
2. 拆解至少覆盖：结构、节奏、角色、信息释放四维。
3. 每次引用参考文本必须生成"借鉴点-改造点"对照表。
4. 成果必须转化为本项目原创表达，不得保留可识别复刻段落。
5. 参考文本使用记录必须归档。

### 产出要求

- `参考文本拆解表.md`
- `借鉴-改造对照表.md`
- `风险说明.md`

### 检查项

- [ ] 引用目的明确（学结构/学节奏/学叙事）。
- [ ] 有明确原创改造策略。
- [ ] 无高相似段落。
- [ ] 拆解结论可转化为执行动作。
- [ ] 使用记录可追溯。

### 失败判定

- 直接套用参考文本表达。
- 只有"喜欢/不喜欢"主观结论，无结构分析。
- 参考使用后未产出可执行改进项。

## 资料与来源规范

### 可执行条款

1. 关键结论必须标注来源类型（数据/经验/推断）。
2. 涉及市场判断时必须区分"已验证数据"与"推断"。
3. 来源记录需可追溯到文件或链接。
4. 低可信来源不得作为唯一依据。
5. 复盘报告中必须注明结论证据链。

### 产出要求

- `来源索引.md`
- `证据链说明.md`
- `结论可信度标注.md`

### 检查项

- [ ] 关键判断均有来源。
- [ ] 推断性结论已明确标注。
- [ ] 来源口径冲突已说明。
- [ ] 过期来源已更新或降权。
- [ ] 证据链与行动建议一致。

### 失败判定

- 重要结论无来源支撑。
- 推断被当作确定事实。
- 证据链断裂导致错误决策。
